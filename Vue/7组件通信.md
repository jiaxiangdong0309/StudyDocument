# 组件通信（Component Communication）

## 什么是组件通信？

### 定义

组件通信（Component Communication）是指在 Vue 应用中，不同组件之间进行数据或消息传递的机制。英文原文：Component Communication。

### 通俗理解

可以把组件通信比作"家人之间的对话"：父母（父组件）可以给孩子（子组件）传递信息，孩子也能通过特定方式向父母反馈，兄弟姐妹之间也能通过"信使"传递消息。

## 核心特征/组成部分

- 父子通信：props、emit
- 兄弟通信：事件总线、状态管理、ref
- 跨层通信：provide/inject
- 支持多种通信模式，适应不同场景

## 工作原理/实现方式

### 1. 父子通信

- **props**：父组件通过 props 向子组件传递数据
- **emit**：子组件通过 $emit 触发自定义事件，向父组件传递消息

### 2. 兄弟通信

- 通过共同的父组件中转
- 使用事件总线（Vue 2）或全局状态管理（Vuex/Pinia）
- ref 获取组件实例（Vue 3）

### 3. 跨层通信

- **provide/inject**：祖先组件通过 provide 提供数据，后代组件通过 inject 注入数据

## 典型应用场景

- 表单组件与父级数据联动
- 复杂页面的模块间协作
- 动态组件、弹窗、通知等全局事件

## 代码示例

### 1. props/emit 父子通信

```vue
<!-- Child.vue -->
<template>
  <button @click="$emit('sayHi', '你好，父组件！')">点击</button>
</template>

<!-- Parent.vue -->
<template>
  <Child @sayHi="(msg) => alert(msg)" />
</template>
<script setup>
import Child from "./Child.vue";
</script>
```

### 2. provide/inject 跨层通信

```vue
<!-- GrandParent.vue -->
<script setup>
import { provide } from "vue";
provide("theme", "dark");
</script>

<!-- Child.vue -->
<script setup>
import { inject } from "vue";
const theme = inject("theme");
</script>
```

### 3. ref 获取子组件实例

```vue
<!-- Parent.vue -->
<template>
  <Child ref="childRef" />
  <button @click="childRef.sayHello()">调用子组件方法</button>
</template>
<script setup>
import { ref } from "vue";
import Child from "./Child.vue";
const childRef = ref();
</script>

<!-- Child.vue -->
<script setup>
function sayHello() {
  alert("Hello from child!");
}
</script>
```

## 优缺点分析

**优点：**

- 灵活多样，适应各种组件结构
- 明确的数据流向，便于维护
- 支持多层级、跨层级通信

**缺点：**

- 通信链路复杂时，维护难度增加
- 滥用全局事件或状态管理可能导致数据混乱

## 总结与扩展阅读

掌握多种组件通信方式，有助于开发高效、可维护的 Vue 应用。建议根据实际场景选择合适的通信方案。
