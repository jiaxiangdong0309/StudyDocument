# 插槽与作用域插槽（Slots & Scoped Slots）

## 什么是插槽与作用域插槽？

### 定义

插槽（Slot）是 Vue 提供的一种内容分发机制，允许父组件向子组件传递任意结构的内容。作用域插槽（Scoped Slot）则允许子组件将数据传递给插槽内容，由父组件决定如何渲染。英文原文：Slot & Scoped Slot。

### 通俗理解

可以把插槽想象成"预留窗口"，父组件可以把内容"塞进"子组件的窗口。作用域插槽则像"带参数的窗口"，子组件把数据递给父组件，父组件决定怎么用。

## 核心特征/组成部分

- 默认插槽、具名插槽、作用域插槽
- 灵活的内容分发和复用
- 支持多层嵌套和动态内容

## 工作原理/实现方式

- 子组件通过 <slot> 标签定义插槽位置
- 父组件通过插槽标签传递内容
- 作用域插槽通过 v-slot 语法获取子组件传递的数据

## 典型应用场景

- 通用布局组件（如 Card、Dialog）
- 表格、列表等高阶组件的自定义渲染
- 复杂内容分发和复用

## 代码示例

### 1. 默认插槽

```vue
<!-- BaseCard.vue -->
<template>
  <div class="card">
    <slot></slot>
  </div>
</template>
```

```vue
<!-- App.vue -->
<template>
  <BaseCard>这里是卡片内容</BaseCard>
</template>
<script setup>
import BaseCard from "./BaseCard.vue";
</script>
```

### 2. 具名插槽

```vue
<!-- BaseLayout.vue -->
<template>
  <header><slot name="header"></slot></header>
  <main><slot></slot></main>
  <footer><slot name="footer"></slot></footer>
</template>
```

```vue
<!-- App.vue -->
<template>
  <BaseLayout>
    <template #header>头部</template>
    主体内容
    <template #footer>底部</template>
  </BaseLayout>
</template>
<script setup>
import BaseLayout from "./BaseLayout.vue";
</script>
```

### 3. 作用域插槽

```vue
<!-- List.vue -->
<template>
  <ul>
    <slot v-for="item in items" :item="item" :key="item.id"></slot>
  </ul>
</template>
<script setup>
const props = defineProps({ items: Array });
</script>
```

```vue
<!-- App.vue -->
<template>
  <List :items="list">
    <template #default="{ item }">
      <li>{{ item.name }}</li>
    </template>
  </List>
</template>
<script setup>
import List from "./List.vue";
const list = [
  { id: 1, name: "苹果" },
  { id: 2, name: "香蕉" },
];
</script>
```

## 优缺点分析

**优点：**

- 内容分发灵活，提升组件复用性
- 支持高阶组件和复杂场景
- 使组件更具扩展性

**缺点：**

- 滥用插槽可能导致组件结构复杂
- 作用域插槽语法初学者理解有门槛

## 总结与扩展阅读

插槽与作用域插槽是 Vue 组件复用和灵活性的关键。建议多实践不同场景下的插槽用法。
