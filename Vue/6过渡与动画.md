# 过渡与动画（Transition & Animation）

## 什么是过渡与动画？

### 定义

过渡与动画是指在 Vue 应用中，元素状态变化时通过动画效果提升用户体验的技术手段。英文原文：Transition & Animation。

### 通俗理解

可以把过渡与动画比作"魔术"：元素出现、消失、移动时加点特效，让界面更生动有趣。

## 核心特征/组成部分

- `<transition>` 和 `<transition-group>` 组件
- 支持 CSS 过渡、CSS 动画、JavaScript 钩子
- 支持进入、离开、列表动画
- 可与第三方动画库结合

## 工作原理/实现方式

- 使用 `<transition>` 包裹需要动画的元素
- 通过 class 切换或 JS 钩子控制动画过程
- 支持自定义动画时长、缓动函数等

## 典型应用场景

- 弹窗、对话框的淡入淡出
- 列表项的增删动画
- 页面切换、菜单展开收起

## 代码示例

### 1. 基本过渡

```vue
<template>
  <button @click="show = !show">切换</button>
  <transition name="fade">
    <p v-if="show">淡入淡出内容</p>
  </transition>
</template>
<script setup>
import { ref } from "vue";
const show = ref(true);
</script>
<style>
.fade-enter-active,
.fade-leave-active {
  transition: opacity 0.5s;
}
.fade-enter-from,
.fade-leave-to {
  opacity: 0;
}
</style>
```

### 2. 列表动画

```vue
<template>
  <button @click="add">添加</button>
  <transition-group name="list" tag="ul">
    <li v-for="item in items" :key="item">{{ item }}</li>
  </transition-group>
</template>
<script setup>
import { ref } from "vue";
const items = ref([1, 2, 3]);
function add() {
  items.value.push(Date.now());
}
</script>
<style>
.list-enter-active,
.list-leave-active {
  transition: all 0.5s;
}
.list-enter-from,
.list-leave-to {
  opacity: 0;
  transform: translateY(30px);
}
</style>
```

## 优缺点分析

**优点：**

- 提升用户体验和界面美观度
- 支持多种动画实现方式
- 易于集成第三方动画库

**缺点：**

- 动画过多可能影响性能
- 复杂动画实现有一定门槛

## 总结与扩展阅读

过渡与动画是提升 Vue 应用交互体验的重要手段。建议结合实际需求合理使用。
