# Android 性能优化 (Performance Optimization)

## 导航

> **核心目标**：让 App 更快、更省、更稳定  
> **重要程度**：⭐⭐⭐⭐⭐（面试必考 + 日常开发核心技能）

## 什么是性能优化？

性能优化就像给汽车做保养——定期检查、及时维护，让它跑得更快、更省油、更耐用。

Android 性能优化的核心关注点：

| 用户感知 | 对应指标 | 优化方向 |
|---------|---------|---------|
| 打开 App 太慢 | 启动时间 | **启动优化** |
| 用着卡顿 | 帧率 / 响应时间 | **卡顿优化** |
| 经常闪退 | 崩溃率 / OOM | **内存优化** |
| 太费电 | 电量消耗 | **电量优化** |
| 安装包太大 | APK 大小 | **包体积优化** |
| 加载数据慢 | 网络耗时 | **网络优化** |
| 界面不流畅 | 渲染耗时 | **布局优化** |
| 读写数据慢 | IO 耗时 | **存储优化** |

## 核心问题预览

### 内存优化
- 什么是内存泄漏？如何检测和解决？
- OOM 的原因有哪些？如何预防？
- 如何分析 MAT、LeakCanary 的报告？

### 布局优化
- 如何减少布局层级？
- 过度绘制如何检测和优化？
- ConstraintLayout 为什么更高效？

### 启动优化
- 冷启动、温启动、热启动的区别？
- 如何测量启动时间？
- 有哪些启动优化的手段？

### 卡顿优化
- 什么是掉帧？为什么会卡顿？
- 如何检测和定位卡顿？
- ANR 的原因和解决方案？

### 包体积优化
- APK 由哪些部分组成？
- 如何压缩资源和代码？
- 动态下发、插件化如何减小包体积？

### 网络优化
- 如何减少网络请求次数？
- 弱网环境如何优化？
- 网络缓存策略有哪些？

### 电量优化
- App 耗电的主要原因？
- 如何检测和分析耗电？
- 后台任务如何省电？

### 存储优化
- SharedPreferences 有什么性能问题？
- 数据库如何优化查询？
- 大文件读写如何优化？

## 性能优化方法论

### 1. 发现问题
- 线上监控：APM 系统、用户反馈
- 线下测试：性能测试工具、自动化测试

### 2. 分析问题
- 定位瓶颈：Profiler、Systrace、MAT
- 找到根因：源码分析、日志追踪

### 3. 解决问题
- 制定方案：评估成本和收益
- 实施优化：渐进式、可回滚

### 4. 验证效果
- 数据对比：优化前后指标对比
- 灰度验证：小范围验证，观察线上表现

### 5. 持续监控
- 防止劣化：CI/CD 集成性能检测
- 持续优化：定期 Review，持续改进

## 总结

性能优化是一个**持续的过程**，不是一次性的工作。核心思路：

1. **有数据**：用工具测量，用数据说话
2. **抓重点**：优先解决影响最大的问题
3. **可验证**：优化效果要能量化
4. **防劣化**：建立监控机制，防止性能回退
