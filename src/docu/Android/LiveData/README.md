# LiveData 知识体系

## 概述

LiveData 是 Android Jetpack 架构组件的核心成员，一个**生命周期感知**的可观察数据持有类。它是连接数据层和 UI 层的桥梁，与 ViewModel 配合使用，实现了优雅的数据驱动 UI 架构。
