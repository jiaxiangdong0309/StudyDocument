# Lifecycle 学习指南

## 概述

Lifecycle 是 Android Jetpack 架构组件的**底层基石**，几乎所有其他架构组件（ViewModel、LiveData、Room 等）都依赖它。它提供了一种**优雅的方式**来感知和响应 Activity/Fragment 的生命周期状态变化。

> **一句话理解**：Lifecycle 就像一个"广播站"📻，Activity/Fragment 生命周期一变化，它就自动通知所有订阅者，再也不用手动在每个生命周期方法里写一堆代码了。

## 为什么要学 Lifecycle？

| 场景 | 没有 Lifecycle | 有 Lifecycle |
|-----|---------------|--------------|
| 资源释放 | 忘记在 onDestroy 释放，内存泄漏 | 自动感知销毁，自动释放 |
| 代码组织 | 生命周期回调塞满各种逻辑，臃肿不堪 | 各组件自己管理，职责清晰 |
| 复用性 | 生命周期逻辑绑定在 Activity 里，无法复用 | 抽成独立组件，随处复用 |
| 测试性 | 难以单独测试生命周期相关逻辑 | 组件独立，易于测试 |

## 相关技术

| 技术 | 关系 | 说明 |
|-----|------|------|
| ViewModel | 依赖 Lifecycle | ViewModel 的存活判断基于 Lifecycle |
| LiveData | 依赖 Lifecycle | LiveData 通过 Lifecycle 实现生命周期感知 |
| Room | 可选依赖 | 可返回 LiveData 类型数据 |
| WorkManager | 可选依赖 | 任务可感知应用生命周期 |
| Compose | 集成 | Compose 有自己的生命周期感知机制 |
