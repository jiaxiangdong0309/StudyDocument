# WorkManager 学习指南

## 概述

WorkManager 是 Android Jetpack 中用于管理**可延迟、可靠执行**的后台任务的组件。它是目前 Android 官方推荐的后台任务解决方案，能够根据设备状态智能调度任务，即使应用退出或设备重启也能保证任务执行。

## 适用场景速查

```
✅ 适合用 WorkManager：
├── 日志上传、数据同步
├── 图片/文件压缩上传
├── 定期清理缓存
├── 周期性数据备份
└── 需要保证执行的后台任务

❌ 不适合用 WorkManager：
├── 需要精确时间执行（用 AlarmManager）
├── 需要立即执行且不能延迟（用 Foreground Service）
├── 简单的异步操作（用协程/RxJava）
└── 需要与用户持续交互（用 Service）
```
