# 自定义 View 学习指南

## 为什么要学自定义 View？

自定义 View 是 Android 开发的**分水岭**——会的人能实现任何设计稿，不会的人只能用现成控件凑合。

```
初级开发：LinearLayout 套 LinearLayout，能显示就行
中级开发：用 ConstraintLayout 优化层级，关注性能
高级开发：任何效果都能自己画出来，还知道怎么画最快
```

## 核心问题预览

### 基础问题
1. View 的坐标系是怎样的？
2. onMeasure、onLayout、onDraw 分别做什么？
3. Canvas 能画哪些基本图形？
4. MeasureSpec 是什么？三种模式有什么区别？

### 进阶问题
5. 如何实现一个圆形头像？
6. 贝塞尔曲线怎么用？能实现什么效果？
7. 自定义 View 怎么做动画？
8. 怎么处理触摸事件？
9. 自定义 View 有哪些性能问题？怎么优化？

### 深度问题
10. View 的绘制流程是怎样的？从哪里开始？
11. invalidate() 和 requestLayout() 的区别？什么时候用哪个？
12. 硬件加速对自定义 View 有什么影响？
13. 自定义 ViewGroup 和自定义 View 有什么区别？
