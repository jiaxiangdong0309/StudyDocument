# ReAct（Reason + Act）

## 什么是 ReAct？

### 定义

ReAct（Reason + Act）是一种结合“推理（Reasoning）”与“行动（Acting）”的智能体（Agent）决策框架。它让 AI 在解决复杂任务时，能够一边思考（推理），一边采取行动（调用工具、检索信息等），并根据每一步的反馈不断调整后续行为。

### 通俗理解

可以把 ReAct 想象成“边想边做”的智能助手。比如你问 AI 一个复杂问题，它会先分析问题（Reason），然后查资料、计算或调用工具（Act），再根据结果继续思考和行动，直到给出最终答案。

## ReAct 的工作流程

1. **推理（Reason）**
   AI 先对当前问题进行分析、分解，明确需要哪些信息或步骤。
2. **行动（Act）**
   根据推理结果，AI 采取具体行动，比如检索资料、调用 API、执行计算等。
3. **观察（Observe）**
   AI 获取行动的反馈或结果。
4. **循环迭代**
   AI 根据新的信息继续推理和行动，直到任务完成。

## 典型应用场景

- **复杂问答**：需要多步推理和外部信息检索的问题。
- **工具增强型 Agent**：如能调用搜索引擎、计算器、数据库等工具的智能体。
- **RAG（检索增强生成）**：结合检索和生成能力，动态获取和整合信息。
- **自动化任务执行**：如自动化办公、流程机器人等。

## 优势

- **更强的推理能力**：能分步思考，逐步解决复杂问题。
- **动态适应**：能根据每一步的反馈灵活调整策略。
- **工具集成**：可与外部工具、API 深度结合，提升智能体能力。

## 白话举例

比如你问 AI：“中国和美国的面积分别是多少？哪个更大？”
传统 AI 可能直接生成答案，但 ReAct Agent 会这样做：

1. Reason：需要分别查找中国和美国的面积。
2. Act：查找中国面积，得到答案。
3. Act：查找美国面积，得到答案。
4. Reason：比较两个面积，判断哪个更大。
5. Act：输出最终结论。
   整个过程就是“边想边查边比”，每一步都可追溯和解释。

## 总结

- ReAct 是一种“推理+行动”结合的智能体决策框架。
- 让 AI 能像人一样，分步思考、动态行动、灵活应对复杂任务。
- 广泛应用于多步推理、工具增强、RAG 等场景。
