# 组件基础（Components）

> 快速了解 React 组件是什么、什么时候用，以及本主题文档导航。

---

## 一句话：组件是什么？

**组件**就是「能复用的 UI 块 + 接收的数据（Props）」：写一个函数，接收参数，返回 JSX，React 帮你挂到页面上。**学了能做什么**：会拆分组件、用 Props 传数据、渲染列表和条件 UI。

---

## 什么时候会用到组件？

| 场景 | 说明 |
|------|------|
| 页面拆成一块块 | 头部、侧栏、列表项、卡片等，每个都是一类组件 |
| 同一块 UI 多处用 | 按钮、输入框、弹窗、空状态等，抽成组件复用 |
| 列表渲染 | 每条数据渲染成一个子组件，用 `key` 标识 |
| 条件显示 | 根据数据/状态决定显示哪一块 UI（条件渲染） |
| 表单与交互 | 输入框、选择器、提交按钮，用受控/非受控方式绑定数据 |

## 核心问题预览（自测用）

- **组件是什么？** 接收 Props、返回 JSX 的函数（或类，现代以函数为主）。
- **什么时候拆组件？** UI 重复、逻辑独立、或单文件过长时。
- **Props 和 state 区别？** Props 父传子、只读；state 组件内部、可更新。
- **列表为什么要 key？** 帮助 React 识别元素，方便 Diff 和复用，**不要用 index 当 key**（列表会增删时）。
- **受控 vs 非受控？** 受控：值由 state 管，用 `value + onChange`；非受控：值在 DOM 里，用 `ref` 取。
