# 反射基础篇 - 让代码"自己看透自己"

## 什么是反射？

### 定义

**反射（Reflection）** 是 Java 提供的一种能力：程序在**运行时**可以检查和操作类的内部结构（字段、方法、构造器），即使这些成员是私有的。

### 通俗理解

想象你去医院体检：
- **正常情况**：医生只能看你外表（公开的方法）
- **用了 X 光**：医生能看到你的骨骼、内脏（私有字段、私有方法）

**反射就是程序的 X 光机**，能"透视"任何类的内部结构。

```kotlin
// 正常调用：只能调用公开方法
user.getName()  // ✅ 可以

// 反射调用：连私有方法都能调
val method = User::class.java.getDeclaredMethod("getSecret")
method.isAccessible = true  // 打开"X光机"
method.invoke(user)  // ✅ 也可以！
```

## 为什么需要反射？

### 技术演进：从写死到灵活

**问题 1：路由跳转写死了**

```kotlin
// ❌ 传统写法：每个页面都要 import，代码耦合
button.setOnClickListener {
    startActivity(Intent(this, UserDetailActivity::class.java))
}
```

**用反射后：通过字符串跳转**

```kotlin
// ✅ ARouter 的做法：模块之间不需要互相依赖
ARouter.getInstance()
    .build("/user/detail")  // 只需要知道路径
    .navigation()

// ARouter 内部实现（简化版）
fun navigation(path: String) {
    val className = routeMap[path]  // "/user/detail" -> "com.app.user.UserDetailActivity"
    val clazz = Class.forName(className)  // 反射加载类
    val intent = Intent(context, clazz)
    context.startActivity(intent)
}
```

**问题 2：JSON 转对象太麻烦**

```kotlin
// ❌ 手动解析：每个字段都要写，改字段名要改多处
val json = """{"name":"张三","age":25}"""
val obj = JSONObject(json)
val user = User(
    name = obj.getString("name"),
    age = obj.getInt("age")
)
```

**用反射后：自动映射**

```kotlin
// ✅ Gson 的做法：自动把 JSON 字段映射到对象字段
val user = Gson().fromJson(json, User::class.java)

// Gson 内部实现（简化版）
fun <T> fromJson(json: String, clazz: Class<T>): T {
    val obj = clazz.newInstance()  // 反射创建对象
    for (field in clazz.declaredFields) {
        field.isAccessible = true  // 允许访问私有字段
        val value = parseJsonValue(json, field.name)
        field.set(obj, value)  // 反射设置字段值
    }
    return obj
}
```

## 反射的核心 API

### 四大天王

| 类 | 作用 | Android 应用 |
|---|------|-------------|
| `Class<T>` | 代表一个类 | 加载插件、路由跳转 |
| `Method` | 代表一个方法 | 调用系统隐藏 API、EventBus 订阅 |
| `Field` | 代表一个字段 | Gson 序列化、修改 final 字段 |
| `Constructor<T>` | 代表一个构造器 | 创建对象、依赖注入 |

### 获取 Class 对象的三种方式

```kotlin
// 方式 1：类名.class / 类名::class.java（编译时就知道类型）
val clazz1 = User::class.java  // Kotlin
val clazz1 = User.class  // Java

// 方式 2：对象.javaClass / 对象.getClass()（已有实例）
val user = User()
val clazz2 = user.javaClass  // Kotlin
val clazz2 = user.getClass()  // Java

// 方式 3：Class.forName("全限定类名")（运行时动态加载）
val clazz3 = Class.forName("com.example.User")  // 最灵活，路由框架常用
```

**三种方式对比**：

| 方式 | 使用场景 | 缺点 |
|-----|---------|------|
| `类名::class.java` | 编译时已知类型 | 需要 import，模块耦合 |
| `对象.javaClass` | 已有实例，想知道具体类型 | 必须先有对象 |
| `Class.forName()` | **路由、插件化**（运行时才知道类名） | 类名写错会抛异常 |

## 基本用法：反射四步走

### 1. 反射创建对象

**场景：ARouter 创建目标 Activity**

```kotlin
// Android 场景：路由框架根据路径创建 Activity
class SimpleRouter {
    private val routeMap = mapOf(
        "/user/detail" to "com.example.user.UserDetailActivity",
        "/order/list" to "com.example.order.OrderListActivity"
    )

    fun navigate(context: Context, path: String) {
        val className = routeMap[path] ?: return
        
        // 反射创建 Activity
        val clazz = Class.forName(className)
        val intent = Intent(context, clazz)
        context.startActivity(intent)
    }
}

// 使用
SimpleRouter().navigate(this, "/user/detail")  // 跳转到用户详情
```

**原理分析**：

```kotlin
// 方式 1：调用无参构造器（最常用）
val clazz = User::class.java
val user = clazz.newInstance()  // 已废弃，推荐用下面的方式
val user = clazz.getDeclaredConstructor().newInstance()  // ✅ 推荐

// 方式 2：调用有参构造器
val constructor = User::class.java.getDeclaredConstructor(String::class.java, Int::class.java)
val user = constructor.newInstance("张三", 25)
```

### 2. 反射访问字段

**场景：Gson 读写私有字段**

```kotlin
// Android 场景：实现一个简易 JSON 序列化
data class User(
    private val name: String,  // 私有字段
    private val age: Int
)

// 即使字段是 private，Gson 也能读写
class SimpleGson {
    fun toJson(obj: Any): String {
        val clazz = obj.javaClass
        val json = StringBuilder("{")
        
        clazz.declaredFields.forEachIndexed { index, field ->
            field.isAccessible = true  // 打破私有限制
            val value = field.get(obj)  // 读取字段值
            json.append("\"${field.name}\":\"$value\"")
            if (index < clazz.declaredFields.size - 1) json.append(",")
        }
        
        json.append("}")
        return json.toString()
    }
}

// 使用
val user = User("张三", 25)
val json = SimpleGson().toJson(user)
println(json)  // {"name":"张三","age":"25"}
```

**API 详解**：

```kotlin
val clazz = User::class.java

// 获取字段
val field1 = clazz.getField("name")           // 只能获取 public 字段
val field2 = clazz.getDeclaredField("name")   // ✅ 能获取任何字段（包括 private）

// 读取字段值
field2.isAccessible = true  // 必须先设置为 true，否则访问 private 字段会报错
val value = field2.get(user)  // 读取 user 对象的 name 字段

// 修改字段值
field2.set(user, "李四")  // user.name = "李四"
```

**getDeclaredField vs getField 对比**：

| 方法 | 能获取的字段 | 能否获取父类字段 |
|-----|-------------|----------------|
| `getDeclaredField()` | 本类所有字段（包括 private） | ❌ 不能 |
| `getField()` | 本类+父类的 **public** 字段 | ✅ 能 |

### 3. 反射调用方法

**场景：EventBus 调用订阅方法**

```kotlin
// Android 场景：实现一个简易事件总线
class SimpleEventBus {
    private val subscribers = mutableMapOf<Any, List<Method>>()

    // 注册订阅者：扫描所有 @Subscribe 注解的方法
    fun register(subscriber: Any) {
        val methods = subscriber.javaClass.declaredMethods.filter { method ->
            method.isAnnotationPresent(Subscribe::class.java)
        }
        subscribers[subscriber] = methods
    }

    // 发送事件：反射调用所有订阅方法
    fun post(event: Any) {
        subscribers.values.flatten().forEach { method ->
            method.isAccessible = true
            method.invoke(subscriber, event)  // 反射调用订阅方法
        }
    }
}

// 使用
class UserActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        SimpleEventBus.getDefault().register(this)
    }

    @Subscribe
    fun onUserLogin(event: LoginEvent) {
        // EventBus 通过反射调用这个方法
        Toast.makeText(this, "登录成功", Toast.LENGTH_SHORT).show()
    }
}
```

**API 详解**：

```kotlin
val clazz = User::class.java

// 获取方法
val method1 = clazz.getMethod("getName")              // 只能获取 public 方法
val method2 = clazz.getDeclaredMethod("getSecret")    // ✅ 能获取任何方法（包括 private）

// 调用方法
method2.isAccessible = true  // 允许调用私有方法
val result = method2.invoke(user)  // 调用 user.getSecret()

// 调用有参方法
val method3 = clazz.getDeclaredMethod("setAge", Int::class.java)
method3.invoke(user, 30)  // user.setAge(30)
```

### 4. 反射访问构造器

**场景：Dagger 依赖注入**

```kotlin
// Android 场景：实现一个简易 IoC 容器
class SimpleIoC {
    private val instances = mutableMapOf<Class<*>, Any>()

    // 注册单例
    inline fun <reified T : Any> register(factory: () -> T) {
        instances[T::class.java] = factory()
    }

    // 获取实例：优先从缓存取，没有就反射创建
    fun <T> get(clazz: Class<T>): T {
        return instances.getOrPut(clazz) {
            // 反射创建对象，并自动注入依赖
            val constructor = clazz.declaredConstructors[0]
            constructor.isAccessible = true
            
            // 递归解析构造器参数
            val params = constructor.parameterTypes.map { get(it) }.toTypedArray()
            constructor.newInstance(*params)
        } as T
    }
}

// 使用
class UserRepository(private val api: ApiService)  // 依赖 ApiService
class UserViewModel(private val repo: UserRepository)  // 依赖 UserRepository

val ioc = SimpleIoC()
ioc.register { ApiService() }
ioc.register { UserRepository(ioc.get(ApiService::class.java)) }

// 自动注入依赖
val viewModel = ioc.get(UserViewModel::class.java)  // IoC 会自动创建并注入依赖
```

## Android 实战：突破私有 API 限制

**场景：获取 ActivityThread（系统隐藏类）**

```kotlin
// Android 内部有很多隐藏 API，无法直接访问
// 例如 ActivityThread.currentApplication()

fun getCurrentApplication(): Application? {
    return try {
        // 反射获取隐藏类
        val activityThreadClass = Class.forName("android.app.ActivityThread")
        
        // 反射调用静态方法
        val method = activityThreadClass.getMethod("currentApplication")
        method.invoke(null) as? Application  // 静态方法传 null
    } catch (e: Exception) {
        null
    }
}
```

**注意事项**：
- Android 9+ 限制了反射私有 API（会有警告，但不影响使用）
- Android 12+ 可能会直接抛异常
- 生产环境慎用，建议用公开 API 替代

## 常见坑点和注意事项

### 1. setAccessible(true) 忘记设置

```kotlin
// ❌ 错误：访问私有成员前忘记设置 isAccessible
val field = User::class.java.getDeclaredField("name")
field.get(user)  // 💥 IllegalAccessException

// ✅ 正确：先设置 isAccessible = true
val field = User::class.java.getDeclaredField("name")
field.isAccessible = true  // 必须加这一行
field.get(user)  // ✅ 正常
```

### 2. 静态方法调用传 null

```kotlin
// 反射调用实例方法：传对象
val method = User::class.java.getMethod("getName")
method.invoke(user)  // ✅ 传实例

// 反射调用静态方法：传 null
val method = Math::class.java.getMethod("max", Int::class.java, Int::class.java)
method.invoke(null, 10, 20)  // ✅ 静态方法传 null
```

### 3. 基本类型 vs 包装类型

```kotlin
// ❌ 错误：int 和 Integer 不一样
val method = User::class.java.getMethod("setAge", Integer::class.java)  // 💥 找不到

// ✅ 正确：用基本类型 int
val method = User::class.java.getMethod("setAge", Int::class.javaPrimitiveType)
// 或者直接用 Kotlin 的 Int::class.java，它会自动映射到 int
```

### 4. 性能问题（后续进阶篇详细讲）

```kotlin
// ❌ 糟糕：每次都反射，性能极差
fun onClick() {
    val method = Activity::class.java.getMethod("finish")
    method.invoke(activity)  // 比直接调用慢 10-50 倍
}

// ✅ 优化：缓存 Method 对象
val methodCache = Activity::class.java.getMethod("finish")
fun onClick() {
    methodCache.invoke(activity)  // 快很多，但还是比直接调用慢
}
```

## 总结

### 核心要点

1. **反射是什么**：程序运行时的"X光机"，能透视和操作类的内部结构
2. **为什么需要**：实现路由、序列化、依赖注入等框架，让代码更灵活
3. **四大 API**：`Class`、`Method`、`Field`、`Constructor`
4. **必须记住**：访问私有成员前要 `isAccessible = true`

### Android 应用场景

| 场景 | 用途 | 典型框架 |
|-----|------|---------|
| 组件化路由 | 通过字符串跳转页面 | ARouter |
| JSON 序列化 | 自动映射字段 | Gson、Moshi |
| 事件总线 | 自动找订阅方法 | EventBus |
| 依赖注入 | 自动创建和注入对象 | Dagger、Hilt |
| 插件化 | 动态加载未安装的代码 | VirtualAPK |
| 热修复 | 运行时替换类 | Tinker |

## 面试检验

### 1. 什么是反射？有什么用？

**答案**：
- **定义**：反射是 Java 在运行时检查和操作类内部结构的能力
- **作用**：实现框架的灵活性，如路由、序列化、依赖注入
- **Android 实例**：ARouter 通过字符串跳转页面，Gson 自动解析 JSON

### 2. 如何通过反射调用私有方法？

**答案**：
```kotlin
val method = clazz.getDeclaredMethod("privateMethod")
method.isAccessible = true  // 关键：打破私有限制
method.invoke(obj)
```

### 3. 反射和 new 对象有什么区别？

**答案**：

| 方式 | 特点 | 适用场景 |
|-----|------|---------|
| `new User()` | 编译时确定类型，性能好 | 普通业务代码 |
| `Class.forName().newInstance()` | 运行时动态加载，灵活但慢 | 框架、路由、插件化 |

**Android 实例**：ARouter 运行时才知道要跳转哪个 Activity，必须用反射。

### 4. getDeclaredMethod 和 getMethod 有什么区别？

**答案**：

| 方法 | 能获取的方法 | 能否获取父类方法 |
|-----|-------------|----------------|
| `getDeclaredMethod()` | 本类所有方法（包括 private） | ❌ 不能 |
| `getMethod()` | 本类+父类的 **public** 方法 | ✅ 能 |

### 5. 为什么 Gson 能访问 private 字段？

**答案**：
- Gson 内部用 `Field.setAccessible(true)` 打破私有限制
- 然后用 `Field.get()` 读取字段值，`Field.set()` 设置字段值
- 这也是为什么 Gson 不需要提供 getter/setter 方法
