# ViewModel 学习指南

## 概述

ViewModel 是 Android Jetpack 架构组件的核心成员，专门用于以**生命周期感知**的方式存储和管理 UI 相关数据。它最大的特点是：**在配置变更（如屏幕旋转）时不会被销毁**，从而完美保留数据。

> **一句话理解**：ViewModel 就像一个"数据保险箱"，Activity/Fragment 重建了，保险箱里的数据依然完好无损。

## 为什么要学 ViewModel？

| 场景 | 没有 ViewModel | 有 ViewModel |
|-----|---------------|--------------|
| 屏幕旋转 | 数据丢失，用户重新填写表单 | 数据完好，无缝体验 |
| 数据共享 | Fragment 之间传参麻烦 | 通过共享 ViewModel 轻松搞定 |
| 代码组织 | UI 和业务逻辑混在一起 | 职责分离，代码清晰 |
| 单元测试 | 难以测试 UI 逻辑 | 业务逻辑独立，易于测试 |

### 基础篇必答题

2. ViewModel 的生命周期是怎样的？

### 进阶篇必答题

2. ViewModelStore 是什么？它是如何工作的？
