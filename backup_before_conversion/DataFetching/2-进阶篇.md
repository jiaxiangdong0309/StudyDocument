# 数据请求 - 进阶篇

## React Query

### 什么是 React Query？

React Query 是一个强大的数据请求库，提供了缓存、自动重试、后台刷新等功能，大大简化了数据请求的管理。

### 为什么需要 React Query？

**传统方式的问题**：

```typescript
// ❌ 传统方式：需要手动管理 loading、error、data
function UserList() {
  const [users, setUsers] = useState([])
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState(null)

  useEffect(() => {
    fetch('/api/users')
      .then(res => res.json())
      .then(data => {
        setUsers(data)
        setLoading(false)
      })
      .catch(err => {
        setError(err)
        setLoading(false)
      })
  }, [])

  // 问题：
  // 1. 代码重复（每个组件都要写这些）
  // 2. 没有缓存（切换页面后重新请求）
  // 3. 没有自动刷新（数据可能过期）
  // 4. 没有错误重试
}
```

**使用 React Query**：

```typescript
// ✅ React Query：自动管理状态、缓存、刷新
import { useQuery } from '@tanstack/react-query'

function UserList() {
  const { data: users, isLoading, error } = useQuery({
    queryKey: ['users'],
    queryFn: () => fetch('/api/users').then(res => res.json())
  })

  if (isLoading) return <div>加载中...</div>
  if (error) return <div>错误: {error.message}</div>

  return <ul>{users.map(u => <li key={u.id}>{u.name}</li>)}</ul>
}
```

### 基本用法：useQuery

```typescript
import { useQuery } from '@tanstack/react-query'

interface User {
  id: string
  name: string
  email: string
}

function UserList() {
  const { data, isLoading, error, refetch } = useQuery({
    queryKey: ['users'],  // 缓存的 key
    queryFn: async () => {
      const response = await fetch('/api/users')
      if (!response.ok) throw new Error('请求失败')
      return response.json() as Promise<User[]>
    }
  })

  if (isLoading) return <div>加载中...</div>
  if (error) return <div>错误: {error.message}</div>

  return (
    <div>
      <button onClick={() => refetch()}>刷新</button>
      <ul>
        {data?.map(user => (
          <li key={user.id}>{user.name}</li>
        ))}
      </ul>
    </div>
  )
}
```

### 数据变更：useMutation

```typescript
import { useMutation, useQueryClient } from '@tanstack/react-query'

function CreateUser() {
  const queryClient = useQueryClient()

  const mutation = useMutation({
    mutationFn: async (newUser: { name: string; email: string }) => {
      const response = await fetch('/api/users', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(newUser)
      })
      return response.json()
    },
    onSuccess: () => {
      // 创建成功后，刷新用户列表
      queryClient.invalidateQueries({ queryKey: ['users'] })
    }
  })

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault()
    mutation.mutate({ name: '张三', email: 'zhangsan@example.com' })
  }

  return (
    <form onSubmit={handleSubmit}>
      <button type="submit" disabled={mutation.isPending}>
        {mutation.isPending ? '创建中...' : '创建用户'}
      </button>
      {mutation.isError && <div>错误: {mutation.error.message}</div>}
      {mutation.isSuccess && <div>创建成功!</div>}
    </form>
  )
}
```

### React Query 的缓存配置

```typescript
const queryClient = new QueryClient({
  defaultOptions: {

      cacheTime: 10 * 60 * 1000,  // 缓存保留 10 分钟
      refetchOnWindowFocus: true,  // 窗口聚焦时刷新

    }
  }
```

## 乐观更新

### 什么是乐观更新？

乐观更新是指在请求还没完成时，先更新 UI，给用户即时反馈。如果请求失败，再回滚。

### 传统方式 vs 乐观更新

```typescript
// ❌ 传统方式：等待请求完成
function LikeButton({ postId }: { postId: string }) {
  const [liked, setLiked] = useState(false)
  const [loading, setLoading] = useState(false)

  const handleLike = async () => {
    setLoading(true)
    await likePost(postId)  // 等待请求完成
    setLiked(true)          // 请求成功后才更新 UI
    setLoading(false)
    // 问题：用户要等待，体验不好
  }

  return (
    <button onClick={handleLike} disabled={loading}>
      {loading ? '...' : liked ? '已赞' : '点赞'}
    </button>
  )
}

// ✅ 乐观更新：立即更新 UI
function LikeButton({ postId }: { postId: string }) {
  const [liked, setLiked] = useState(false)

  const handleLike = async () => {
    setLiked(true)  // 立即更新 UI

    try {
      await likePost(postId)  // 后台请求
    } catch (error) {
      setLiked(false)  // 失败时回滚
      alert('点赞失败')
    }
  }

  return (
    <button onClick={handleLike}>
      {liked ? '已赞' : '点赞'}
    </button>
  )
}
```

### React Query 的乐观更新

```typescript
import { useMutation, useQueryClient } from '@tanstack/react-query'

function TodoList() {
  const queryClient = useQueryClient()

  const toggleTodo = useMutation({
    mutationFn: async (todoId: string) => {
      await fetch(`/api/todos/${todoId}/toggle`, { method: 'PUT' })
    },
    onMutate: async (todoId) => {
      // 1. 取消正在进行的查询
      await queryClient.cancelQueries({ queryKey: ['todos'] })

      // 2. 保存之前的数据（用于回滚）
      const previousTodos = queryClient.getQueryData(['todos'])

      // 3. 乐观更新：立即更新缓存
      queryClient.setQueryData(['todos'], (old: Todo[]) =>
        old.map(todo =>
          todo.id === todoId
            ? { ...todo, completed: !todo.completed }
            : todo
        )
      )

      // 4. 返回上下文（用于回滚）
      return { previousTodos }
    },
    onError: (err, todoId, context) => {
      // 5. 失败时回滚
      queryClient.setQueryData(['todos'], context?.previousTodos)
    },
    onSettled: () => {
      // 6. 无论成功失败，都刷新数据
      queryClient.invalidateQueries({ queryKey: ['todos'] })
    }
  })

  return (
    <ul>
      {todos?.map(todo => (
        <li key={todo.id}>
          <input
            type="checkbox"
            checked={todo.completed}
            onChange={() => toggleTodo.mutate(todo.id)}
          />
          {todo.title}
        </li>
      ))}
    </ul>
  )
}
```

## 无限滚动

### 什么是无限滚动？

无限滚动是指滚动到页面底部时自动加载更多数据，常用于社交媒体、新闻列表等。

### 使用 useInfiniteQuery

```typescript
import { useInfiniteQuery } from '@tanstack/react-query'
import { useEffect, useRef } from 'react'

interface Post {
  id: string
  title: string
  content: string
}

interface PostsResponse {
  posts: Post[]
  nextCursor: number | null
}

function InfinitePostList() {
  const {
    data,
    fetchNextPage,
    hasNextPage,
    isFetchingNextPage
  } = useInfiniteQuery({
    queryKey: ['posts'],
    queryFn: async ({ pageParam = 0 }) => {
      const response = await fetch(`/api/posts?cursor=${pageParam}`)
      return response.json() as Promise<PostsResponse>
    },
    getNextPageParam: (lastPage) => lastPage.nextCursor,
    initialPageParam: 0
  })

  // 滚动到底部时加载更多
  const observerTarget = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const observer = new IntersectionObserver(
      entries => {
        if (entries[0].isIntersecting && hasNextPage) {
          fetchNextPage()
        }
      },
      { threshold: 1 }
    )

    const target = observerTarget.current
    if (target) {
      observer.observe(target)
    }

    return () => {
      if (target) {
        observer.unobserve(target)
      }
    }
  }, [hasNextPage, fetchNextPage])

  return (
    <div>
      {data?.pages.map((page, i) => (
        <div key={i}>
          {page.posts.map(post => (
            <div key={post.id} className="post">
              <h3>{post.title}</h3>
              <p>{post.content}</p>
            </div>
          ))}
        </div>
      ))}

      <div ref={observerTarget} />

      {isFetchingNextPage && <div>加载更多...</div>}
      {!hasNextPage && <div>没有更多了</div>}
    </div>
  )
}
```

## SWR（备选方案）

### 什么是 SWR？

SWR 是 Vercel 开发的数据请求库，名字来自 "stale-while-revalidate"（先返回缓存，后台刷新）。

### 3. 防抖搜索

```typescript
import { useState, useEffect } from 'react'
import { useQuery } from '@tanstack/react-query'
import { useDebouncedValue } from './hooks/useDebouncedValue'

function SearchUsers() {
  const [keyword, setKeyword] = useState('')
  const debouncedKeyword = useDebouncedValue(keyword, 500)  // 500ms 防抖

  const { data: users, isLoading } = useQuery({
    queryKey: ['users', 'search', debouncedKeyword],
    queryFn: () => apiClient.get('/users/search', { params: { q: debouncedKeyword } }),
    enabled: debouncedKeyword.length > 0  // 有关键词时才请求
  })

  return (
    <div>
      <input
        type="text"
        value={keyword}
        onChange={e => setKeyword(e.target.value)}
        placeholder="搜索用户..."
      />

      {isLoading && <div>搜索中...</div>}

      {users && (
        <ul>
          {users.map(user => (
            <li key={user.id}>{user.name}</li>
          ))}
        </ul>
      )}
    </div>
  )
}

// hooks/useDebouncedValue.ts
import { useState, useEffect } from 'react'

export function useDebouncedValue<T>(value: T, delay: number): T {
  const [debouncedValue, setDebouncedValue] = useState(value)

  useEffect(() => {
    const timer = setTimeout(() => {
      setDebouncedValue(value)
    }, delay)

    return () => clearTimeout(timer)
  }, [value, delay])

  return debouncedValue
}
```

```typescript
// 1. 创建防抖 Hook
function useDebouncedValue<T>(value: T, delay: number): T {
  const [debouncedValue, setDebouncedValue] = useState(value)

  useEffect(() => {
    const timer = setTimeout(() => {
      setDebouncedValue(value)
    }, delay)

    return () => clearTimeout(timer)
  }, [value, delay])

  return debouncedValue
}

// 2. 使用
function SearchUsers() {
  const [keyword, setKeyword] = useState('')
  const debouncedKeyword = useDebouncedValue(keyword, 500)

  const { data } = useQuery({
    queryKey: ['users', 'search', debouncedKeyword],
    queryFn: () => searchUsers(debouncedKeyword),
    enabled: debouncedKeyword.length > 0
  })

  return <input value={keyword} onChange={e => setKeyword(e.target.value)} />
}
```

**好处**：避免用户每输入一个字符就发送请求，减少服务器压力

## 总结

数据请求是 React 应用的核心功能，React Query 等工具大大简化了数据请求的管理。

**核心要点**：
- React Query 提供缓存、自动刷新、错误重试等功能

- 无限滚动用 `useInfiniteQuery` 实现
- 搜索功能需要防抖避免频繁请求
- 统一管理请求函数和错误处理
