# Android 增量更新（Incremental Update）

## 概述

增量更新是一种只下载新旧版本差异内容的 APK 更新方式，可以大幅减少用户更新时的流量消耗和等待时间。就像你搬家时，不用把所有家具都重新买一遍，只需要带上新增的东西就行。

## 重要程度

| 场景 | 重要程度 | 说明 |
|------|---------|------|
| 大型 App 更新 | ⭐⭐⭐⭐⭐ | 动辄 100MB+ 的包，增量更新可以省 80%+ 流量 |
| 中小型 App | ⭐⭐⭐ | 包体积小，收益相对有限 |
| 频繁迭代的应用 | ⭐⭐⭐⭐⭐ | 用户频繁更新，累计流量节省明显 |
| 海外/弱网地区 | ⭐⭐⭐⭐⭐ | 网络条件差，小包是刚需 |

## 技术选型对比

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| bsdiff/bspatch | 压缩率高、成熟稳定 | 内存消耗大、速度较慢 | 通用场景 |
| xdelta3 | 速度快、内存友好 | 压缩率略低 | 大文件、内存敏感场景 |
| Google Smart Update | 官方支持、集成简单 | 仅 Google Play | Google Play 分发 |
| 自研方案 | 可定制 | 开发成本高 | 特殊需求 |
