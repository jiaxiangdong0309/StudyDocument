# React Router - 基础篇

## 什么是 React Router？

### 定义

React Router 是 React 官方推荐的**路由管理库**，用于在单页应用（SPA）中实现页面导航和 URL 管理。它让你可以根据 URL 显示不同的组件，而不需要刷新整个页面。

### 通俗理解

想象一个图书馆：

- **传统多页应用**：每次换书都要走出图书馆，重新进入另一个图书馆（刷新整个页面）
- **单页应用 + 路由**：在同一个图书馆里，根据书架标签找到不同的书（切换组件，不刷新页面）

React Router 就像图书馆的导航系统，帮你根据"地址"（URL）找到对应的"内容"（组件）。

### 解决的问题

```typescript
// ❌ 没有路由：用状态控制显示哪个页面，URL 不变
function App() {
  const [page, setPage] = useState('home')

  return (
    <div>
      <button onClick={() => setPage('home')}>首页</button>
      <button onClick={() => setPage('about')}>关于</button>

      {page === 'home' && <Home />}
      {page === 'about' && <About />}
      {/* 问题：URL 不变，无法分享链接，无法前进/后退 */}
    </div>
  )
}

// ✅ 使用路由：URL 和页面同步
function App() {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">首页</Link>
        <Link to="/about">关于</Link>
      </nav>

      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
      </Routes>
      {/* URL 变化，可以分享链接，支持前进/后退 */}
    </BrowserRouter>
  )
}
```

## 什么时候用 React Router？

### 适用场景

| 场景 | 说明 | 示例 |
|-----|------|------|
| **多页面应用** | 需要多个独立的页面 | 首页、关于、用户中心 |
| **URL 参数** | 需要通过 URL 传递参数 | `/user/123`、`/post/456` |
| **嵌套路由** | 页面内有子页面 | `/dashboard/profile`、`/dashboard/settings` |
| **分享链接** | 需要分享特定页面的链接 | 分享商品详情页 |
| **浏览器历史** | 需要支持前进/后退 | 用户可以返回上一页 |

### 不需要路由的场景

| 场景 | 原因 | 替代方案 |
|-----|------|---------|
| **单页面应用** | 只有一个页面，没有导航 | 不需要路由 |
| **弹窗/抽屉** | 临时显示的内容 | 用状态控制显示/隐藏 |
| **Tab 切换** | 页面内的标签切换 | 用状态控制当前 Tab |

**核心组件**：

| 组件 | 作用 | 说明 |
|-----|------|------|
| **BrowserRouter** | 路由容器 | 包裹整个应用，提供路由上下文 |
| **Routes** | 路由配置容器 | 包含多个 Route，匹配第一个符合的路由 |
| **Route** | 单个路由规则 | 定义路径和对应的组件 |

## 路由跳转的方式

### 方式 1：声明式导航（Link）

**适用场景**：导航栏、菜单、按钮等静态链接

```typescript
import { Link } from 'react-router-dom'

function Nav() {
  return (
    <nav>
      <Link to="/">首页</Link>
      <Link to="/about">关于</Link>
      <Link to="/contact">联系我们</Link>
    </nav>
  )
}
```

**特点**：
- 类似 HTML 的 `<a>` 标签
- 点击后不会刷新页面
- 会自动添加 `active` 类名（可用于高亮当前页）

### 方式 2：编程式导航（useNavigate）

**适用场景**：登录后跳转、表单提交后跳转、条件跳转

```typescript
import { useNavigate } from 'react-router-dom'

function LoginForm() {
  const navigate = useNavigate()

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault()

    // 登录逻辑
    const success = await login()

    if (success) {
      // 登录成功，跳转到首页
      navigate('/')
    } else {
      alert('登录失败')
    }
  }

  return (
    <form onSubmit={handleSubmit}>
      <input type="text" placeholder="用户名" />
      <input type="password" placeholder="密码" />
      <button type="submit">登录</button>
    </form>
  )
}
```

**常用方法**：

```typescript
const navigate = useNavigate()

// 跳转到指定路径
navigate('/home')

// 跳转并传递状态
navigate('/user', { state: { from: 'login' } })

// 后退
navigate(-1)

// 前进
navigate(1)

// 替换当前历史记录（不能后退）
navigate('/home', { replace: true })
```

### 方式 3：NavLink（带激活状态的链接）

**适用场景**：导航栏需要高亮当前页

```typescript
import { NavLink } from 'react-router-dom'

function Nav() {
  return (
    <nav>
      <NavLink
        to="/"
        className={({ isActive }) => isActive ? 'active' : ''}
      >
        首页
      </NavLink>

      <NavLink
        to="/about"
        style={({ isActive }) => ({
          color: isActive ? 'red' : 'black'
        })}
      >
        关于
      </NavLink>
    </nav>
  )
}
```

## URL 参数传递

### 1. 动态路由参数（useParams）

**场景**：用户详情、文章详情等需要根据 ID 显示不同内容的页面

```typescript
import { Routes, Route, useParams, Link } from 'react-router-dom'

// 1. 配置动态路由
function App() {
  return (
    <Routes>
      <Route path="/user/:id" element={<UserDetail />} />
      <Route path="/post/:id" element={<PostDetail />} />
    </Routes>
  )
}

// 2. 获取参数
function UserDetail() {
  const { id } = useParams()  // 获取 URL 中的 id

  return (
    <div>
      <h1>用户详情</h1>
      <p>用户 ID: {id}</p>
    </div>
  )
}

// 3. 跳转时传递参数
function UserList() {
  const users = [
    { id: '1', name: '张三' },
    { id: '2', name: '李四' }
  ]

  return (
    <div>
      {users.map(user => (
        <Link key={user.id} to={`/user/${user.id}`}>
          {user.name}
        </Link>
      ))}
    </div>
  )
}
```

**多个参数**：

```typescript
// 路由配置
<Route path="/post/:category/:id" element={<PostDetail />} />

// 获取参数
function PostDetail() {
  const { category, id } = useParams()
  return <div>分类: {category}, ID: {id}</div>
}

// 跳转
<Link to="/post/tech/123">科技文章 123</Link>
```

### 2. 查询参数（useSearchParams）

**场景**：搜索、筛选、分页等需要传递多个可选参数

```typescript
import { useSearchParams, Link } from 'react-router-dom'

// 1. 获取查询参数
function ProductList() {
  const [searchParams, setSearchParams] = useSearchParams()

  const category = searchParams.get('category') || 'all'
  const page = searchParams.get('page') || '1'

  return (
    <div>
      <h1>商品列表</h1>
      <p>分类: {category}, 页码: {page}</p>

      {/* 更新查询参数 */}
      <button onClick={() => setSearchParams({ category: 'tech', page: '2' })}>
        切换到科技分类第 2 页
      </button>
    </div>
  )
}

// 2. 跳转时传递查询参数
function CategoryNav() {
  return (
    <nav>
      <Link to="/products?category=tech&page=1">科技</Link>
      <Link to="/products?category=fashion&page=1">时尚</Link>
    </nav>
  )
}
```

### 3. 状态传递（useLocation）

**场景**：跳转时传递临时数据，不显示在 URL 中

```typescript
import { useNavigate, useLocation } from 'react-router-dom'

// 1. 跳转时传递状态
function ProductList() {
  const navigate = useNavigate()

  const handleBuy = (product: Product) => {
    navigate('/checkout', {
      state: { product, from: 'product-list' }
    })
  }

  return <button onClick={() => handleBuy(product)}>购买</button>
}

// 2. 接收状态
function Checkout() {
  const location = useLocation()
  const { product, from } = location.state || {}

  return (
    <div>
      <h1>结算</h1>
      <p>商品: {product?.name}</p>
      <p>来源: {from}</p>
    </div>
  )
}
```

## 完整示例：博客应用

### 需求

- 首页显示文章列表
- 点击文章跳转到详情页
- 详情页显示文章内容
- 支持返回首页

### 代码实现

```typescript
import { BrowserRouter, Routes, Route, Link, useParams, useNavigate } from 'react-router-dom'
import { useState } from 'react'

// 1. 定义类型
interface Post {
  id: string
  title: string
  content: string
  author: string
}

// 2. 模拟数据
const posts: Post[] = [
  { id: '1', title: 'React 入门', content: 'React 是一个用于构建用户界面的 JavaScript 库...', author: '张三' },
  { id: '2', title: 'TypeScript 基础', content: 'TypeScript 是 JavaScript 的超集...', author: '李四' },
  { id: '3', title: 'Hooks 详解', content: 'Hooks 是 React 16.8 引入的新特性...', author: '王五' }
]

// 3. 主应用
function App() {
  return (
    <BrowserRouter>
      <div className="app">
        <header>
          <h1>我的博客</h1>
          <nav>
            <Link to="/">首页</Link>
            <Link to="/about">关于</Link>
          </nav>
        </header>

        <main>
          <Routes>
            <Route path="/" element={<Home />} />
            <Route path="/post/:id" element={<PostDetail />} />
            <Route path="/about" element={<About />} />
            <Route path="*" element={<NotFound />} />
          </Routes>
        </main>
      </div>
    </BrowserRouter>
  )
}

// 4. 首页 - 文章列表
function Home() {
  return (
    <div>
      <h2>文章列表</h2>
      <div className="post-list">
        {posts.map(post => (
          <div key={post.id} className="post-item">
            <h3>
              <Link to={`/post/${post.id}`}>{post.title}</Link>
            </h3>
            <p>作者: {post.author}</p>
          </div>
        ))}
      </div>
    </div>
  )
}

// 5. 文章详情页
function PostDetail() {
  const { id } = useParams()
  const navigate = useNavigate()

  // 根据 ID 查找文章
  const post = posts.find(p => p.id === id)

  if (!post) {
    return <div>文章不存在</div>
  }

  return (
    <div>
      <button onClick={() => navigate(-1)}>返回</button>

      <article>
        <h2>{post.title}</h2>
        <p className="author">作者: {post.author}</p>
        <div className="content">{post.content}</div>
      </article>

      <div className="actions">
        <button onClick={() => navigate('/')}>回到首页</button>
      </div>
    </div>
  )
}

// 6. 关于页面
function About() {
  return (
    <div>
      <h2>关于我们</h2>
      <p>这是一个使用 React Router 构建的博客应用。</p>
    </div>
  )
}

// 7. 404 页面
function NotFound() {
  const navigate = useNavigate()

  return (
    <div>
      <h2>404 - 页面不存在</h2>
      <button onClick={() => navigate('/')}>回到首页</button>
    </div>
  )
}

export default App
```

### 代码说明

| 部分 | 说明 |
|-----|------|
| **BrowserRouter** | 包裹整个应用，提供路由功能 |
| **Routes + Route** | 配置路由规则，匹配 URL 显示对应组件 |
| **Link** | 声明式导航，点击跳转到指定路径 |
| **useParams** | 获取 URL 中的动态参数（如 `:id`） |
| **useNavigate** | 编程式导航，用于按钮点击后跳转 |
| **path="*"** | 匹配所有未定义的路由，用于 404 页面 |

## 常见问题

### 1. Link 和 a 标签有什么区别？

**区别**：

| 特性 | Link | a 标签 |
|-----|------|-------|
| **刷新页面** | 不刷新 | 刷新整个页面 |
| **性能** | 快（只更新组件） | 慢（重新加载所有资源） |
| **状态保留** | 保留 | 丢失 |
| **使用场景** | 应用内导航 | 跳转到外部网站 |

```typescript
// ✅ 应用内导航用 Link
<Link to="/about">关于</Link>

// ✅ 跳转到外部网站用 a 标签
<a href="https://google.com">Google</a>
```

### 2. 如何获取当前路由信息？

```typescript
import { useLocation, useParams, useSearchParams } from 'react-router-dom'

function CurrentRoute() {
  const location = useLocation()  // 当前路由信息
  const params = useParams()      // 动态参数
  const [searchParams] = useSearchParams()  // 查询参数

  return (
    <div>
      <p>当前路径: {location.pathname}</p>
      <p>动态参数: {JSON.stringify(params)}</p>
      <p>查询参数: {searchParams.toString()}</p>
    </div>
  )
}
```

### 3. 如何实现路由跳转后滚动到顶部？

**问题**：切换路由后，页面停留在之前的滚动位置

**解决方案**：

```typescript
import { useEffect } from 'react'
import { useLocation } from 'react-router-dom'

function ScrollToTop() {
  const { pathname } = useLocation()

  useEffect(() => {
    window.scrollTo(0, 0)
  }, [pathname])

  return null
}

function App() {
  return (
    <BrowserRouter>
      <ScrollToTop />  {/* 添加这个组件 */}
      <Routes>
        {/* 路由配置 */}
      </Routes>
    </BrowserRouter>
  )
}
```

### 4. 如何实现路由跳转前确认？

**场景**：表单未保存，离开页面前提示用户

```typescript
import { useEffect } from 'react'
import { useNavigate, useBlocker } from 'react-router-dom'

function EditForm() {
  const [hasUnsavedChanges, setHasUnsavedChanges] = useState(false)

  // 阻止路由跳转
  useEffect(() => {
    const handleBeforeUnload = (e: BeforeUnloadEvent) => {
      if (hasUnsavedChanges) {
        e.preventDefault()
        e.returnValue = ''
      }
    }

    window.addEventListener('beforeunload', handleBeforeUnload)
    return () => window.removeEventListener('beforeunload', handleBeforeUnload)
  }, [hasUnsavedChanges])

  return (
    <form onChange={() => setHasUnsavedChanges(true)}>
      {/* 表单内容 */}
    </form>
  )
}
```

### 5. BrowserRouter 和 HashRouter 有什么区别？

| 特性 | BrowserRouter | HashRouter |
|-----|--------------|-----------|
| **URL 格式** | `/about` | `/#/about` |
| **服务器配置** | 需要配置 | 不需要 |
| **SEO** | 友好 | 不友好 |
| **推荐度** | 推荐 | 不推荐 |

**建议**：优先使用 `BrowserRouter`，只有在无法配置服务器时才用 `HashRouter`。

**服务器配置**（以 Nginx 为例）：

```nginx
location / {
  try_files $uri $uri/ /index.html;
}
```

### 问题 5：如何实现 404 页面？

<details>
<summary>点击查看答案</summary>

**方法**：使用 `path="*"` 匹配所有未定义的路由

```typescript
<Routes>
  <Route path="/" element={<Home />} />
  <Route path="/about" element={<About />} />
  <Route path="*" element={<NotFound />} />  {/* 放在最后 */}
</Routes>

function NotFound() {
  const navigate = useNavigate()

  return (
    <div>
      <h1>404 - 页面不存在</h1>
      <button onClick={() => navigate('/')}>回到首页</button>
    </div>
  )
}
```

**注意**：`path="*"` 必须放在最后，因为路由是按顺序匹配的。
