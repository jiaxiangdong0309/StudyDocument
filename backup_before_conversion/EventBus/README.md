# EventBus 事件总线知识体系

## 概述

EventBus 是 Android 开发中实现**组件间解耦通信**的利器。它基于发布-订阅模式，让不同组件（Activity、Fragment、Service 等）可以在不直接引用对方的情况下进行通信。就像公司里的公告板——发布者只管贴公告，订阅者自己来看，双方不需要认识。

3. 什么是粘性事件？解决了什么问题？
4. 注册/反注册的正确时机是什么？
5. EventBus 会内存泄漏吗？怎么避免？

### 进阶篇

1. EventBus 和 RxBus、LiveDataBus 各有什么优缺点？
2. 什么场景下不该用 EventBus？
3. 如何避免事件总线导致的代码难以追踪问题？
4. EventBus 索引（Index）有什么作用？如何配置？
5. 如何设计一个更好的事件命名规范？

### 源码篇

4. EventBus 的设计有哪些可借鉴之处？
