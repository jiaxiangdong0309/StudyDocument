# Cursor Tab 快速用法

- 编辑代码时，自动弹出补全建议。
- 按 `Tab` 键接受建议，按 `Esc` 拒绝。
- 按 `Ctrl/⌘ + →` 可逐词接受。
- 右下角状态栏可开关 Tab 功能。

适合日常代码补全和多行修改。

# Cursor Agent（Chat）主要模式与用法

1. **Agent 模式**
   - 作用：AI 可自动分析和修改整个代码库，适合实现新功能、全局重构。
2. **Ask 模式**
   - 作用：提问、获取解释、让 AI 规划方案，不直接改代码。
3. **Manual（手动）模式**
   - 作用：只对你指定的内容做精确编辑，适合小范围调整。
4. **自定义模式**
   - 作用：可自定义工作流和模型，满足特殊需求。

**区别**：

- Agent 适合全局自动化和批量修改。
- Ask 适合问答和理解代码。
- Manual 适合精细、可控的小范围编辑。
- 自定义模式灵活组合。

**如何使用**：

- 在侧边栏用 `⌘+L`（Mac）或 `Ctrl+L`（Win/Linux）打开 Agent。
- 输入需求或问题，选择上方的模式（Agent/Ask/Manual/自定义）。
- 按需切换模式，描述你的需求，AI 会自动响应。
