# MMKV 进阶篇

## 多进程支持

### 为什么需要多进程？

Android 应用有时需要在多个进程中运行：

```xml
<!-- AndroidManifest.xml -->
<service
    android:name=".PushService"
    android:process=":push" />  <!-- 推送服务独立进程 -->

<provider
    android:name=".DataProvider"
    android:process=":data" />  <!-- 数据提供者独立进程 -->
```

多进程场景下，SharedPreferences 会出现数据不同步的问题，而 MMKV 原生支持多进程。

### MMKV 多进程使用

```kotlin
// 创建支持多进程的 MMKV 实例
val kv = MMKV.mmkvWithID("multi_process_data", MMKV.MULTI_PROCESS_MODE)

// 进程 A 写入
kv.encode("shared_key", "value from process A")

// 进程 B 立即可以读到最新值
val value = kv.decodeString("shared_key", "")
```

### 加密密钥管理

```kotlin
// 最佳实践：使用 Android Keystore 生成和存储密钥
object SecureKeyManager {
    
    private const val KEY_ALIAS = "mmkv_encryption_key"
    private const val KEYSTORE_PROVIDER = "AndroidKeyStore"
    
    // 获取或创建加密密钥
    fun getOrCreateKey(): String {
        val keyStore = KeyStore.getInstance(KEYSTORE_PROVIDER).apply { load(null) }
        
        return if (keyStore.containsAlias(KEY_ALIAS)) {
            // 已存在，读取
            getExistingKey()
        } else {
            // 不存在，创建
            createNewKey()
        }
    }
    
    private fun createNewKey(): String {
        // Android 6.0+ 使用 KeyGenParameterSpec
        val keyGenerator = KeyGenerator.getInstance(
            KeyProperties.KEY_ALGORITHM_AES,
            KEYSTORE_PROVIDER
        )
        
        val spec = KeyGenParameterSpec.Builder(
            KEY_ALIAS,
            KeyProperties.PURPOSE_ENCRYPT or KeyProperties.PURPOSE_DECRYPT
        )
            .setBlockModes(KeyProperties.BLOCK_MODE_GCM)
            .setEncryptionPaddings(KeyProperties.ENCRYPTION_PADDING_NONE)
            .setKeySize(256)
            .build()
        
        keyGenerator.init(spec)
        val secretKey = keyGenerator.generateKey()
        
        // 返回密钥的编码（实际使用中需要更复杂的处理）
        return Base64.encodeToString(secretKey.encoded, Base64.NO_WRAP).take(16)
    }
    
    private fun getExistingKey(): String {
        val keyStore = KeyStore.getInstance(KEYSTORE_PROVIDER).apply { load(null) }
        val entry = keyStore.getEntry(KEY_ALIAS, null) as KeyStore.SecretKeyEntry
        return Base64.encodeToString(entry.secretKey.encoded, Base64.NO_WRAP).take(16)
    }
}

// 使用安全密钥
val secureKey = SecureKeyManager.getOrCreateKey()
val secureKv = MMKV.mmkvWithID("secure_data", MMKV.SINGLE_PROCESS_MODE, secureKey)
```

### 从 SharedPreferences 迁移

```kotlin
// 方式一：使用 importFromSharedPreferences（推荐）
fun migrateFromSP(context: Context) {
    val oldSp = context.getSharedPreferences("old_config", Context.MODE_PRIVATE)
    val newKv = MMKV.mmkvWithID("new_config")
    
    // 导入所有数据
    val count = newKv.importFromSharedPreferences(oldSp)
    Log.d("MMKV", "迁移了 $count 条数据")
    
    // 清空旧数据
    oldSp.edit().clear().apply()
}

// 方式二：手动迁移（需要更细粒度控制时）
fun manualMigrate(context: Context) {
    val oldSp = context.getSharedPreferences("old_config", Context.MODE_PRIVATE)
    val newKv = MMKV.mmkvWithID("new_config")
    
    // 检查是否已迁移
    if (newKv.decodeBool("migrated", false)) {
        return
    }
    
    // 逐个迁移
    oldSp.all.forEach { (key, value) ->
        when (value) {
            is String -> newKv.encode(key, value)
            is Int -> newKv.encode(key, value)
            is Long -> newKv.encode(key, value)
            is Float -> newKv.encode(key, value)
            is Boolean -> newKv.encode(key, value)
            is Set<*> -> {
                @Suppress("UNCHECKED_CAST")
                newKv.encode(key, value as Set<String>)
            }
        }
    }
    
    // 标记已迁移
    newKv.encode("migrated", true)
    
    // 清空旧数据
    oldSp.edit().clear().apply()
}
```

```kotlin
    companion object {
        private const val SP_NAME = "app_config"
        private const val MIGRATED_KEY = "__migrated_to_mmkv__"
        
        @Volatile
        private var instance: PreferencesManager? = null
        
        fun getInstance(context: Context): PreferencesManager {
            return instance ?: synchronized(this) {
                instance ?: PreferencesManager(context.applicationContext).also {
                    instance = it
                }
            }
        }
    }
    
    private val mmkv: MMKV
    
    init {
        mmkv = MMKV.mmkvWithID(SP_NAME)
        
        // 首次运行时迁移
        if (!mmkv.decodeBool(MIGRATED_KEY, false)) {
            migrateFromSP(context)
        }
    }
    
    private fun migrateFromSP(context: Context) {
        val oldSp = context.getSharedPreferences(SP_NAME, Context.MODE_PRIVATE)
        mmkv.importFromSharedPreferences(oldSp)
        mmkv.encode(MIGRATED_KEY, true)
        
        // 删除旧 SP 文件
        oldSp.edit().clear().apply()
        val spFile = File(context.filesDir.parent, "shared_prefs/$SP_NAME.xml")
        spFile.delete()
    }
    
    // 提供与 SP 相同的 API
    fun getString(key: String, default: String): String {
        return mmkv.decodeString(key, default) ?: default
    }
    
    fun putString(key: String, value: String) {
        mmkv.encode(key, value)
    }
    
    fun getInt(key: String, default: Int): Int {
        return mmkv.decodeInt(key, default)
    }
    
    fun putInt(key: String, value: Int) {
        mmkv.encode(key, value)
```

### 数据版本管理

```kotlin
// 处理数据格式升级
object DataVersionManager {
    private const val VERSION_KEY = "__data_version__"
    private const val CURRENT_VERSION = 3
    
    fun checkAndUpgrade(kv: MMKV) {
        val oldVersion = kv.decodeInt(VERSION_KEY, 1)
        
        if (oldVersion < CURRENT_VERSION) {
            upgrade(kv, oldVersion, CURRENT_VERSION)
        }
    }
    
    private fun upgrade(kv: MMKV, from: Int, to: Int) {
        var version = from
        
        while (version < to) {
            when (version) {
                1 -> upgradeV1ToV2(kv)
                2 -> upgradeV2ToV3(kv)
            }
            version++
        }
        
        kv.encode(VERSION_KEY, to)
    }
    
    // V1 → V2：字段重命名
    private fun upgradeV1ToV2(kv: MMKV) {
        val oldValue = kv.decodeString("userName", null)
        if (oldValue != null) {
            kv.encode("user_name", oldValue)
            kv.removeValueForKey("userName")
        }
    }
    
    // V2 → V3：数据格式变更
    private fun upgradeV2ToV3(kv: MMKV) {
        // 例如：将分散的用户信息合并成对象
        val name = kv.decodeString("user_name", "")
        val age = kv.decodeInt("user_age", 0)
        
        // 存储为 JSON
        val userJson = """{"name":"$name","age":$age}"""
        kv.encode("user_info", userJson)
        
        // 删除旧字段
        kv.removeValuesForKeys(arrayOf("user_name", "user_age"))
    }
}
```

```kotlin
object MMKVBackupManager {
    
    // 备份所有 MMKV 数据
    fun backup(context: Context, backupDir: File): Boolean {
        val mmkvDir = File(MMKV.getRootDir())
        
        if (!mmkvDir.exists()) return false
        
        return try {
            // 复制整个 mmkv 目录
            mmkvDir.copyRecursively(File(backupDir, "mmkv_backup"), overwrite = true)
            true
        } catch (e: Exception) {
            Log.e("MMKVBackup", "备份失败", e)
            false
        }
    }
    
    // 恢复 MMKV 数据
    fun restore(context: Context, backupDir: File): Boolean {
        val backupMmkvDir = File(backupDir, "mmkv_backup")
        val mmkvDir = File(MMKV.getRootDir())
        
        if (!backupMmkvDir.exists()) return false
        
        return try {
            // 关闭所有 MMKV 实例
            MMKV.onExit()
            
            // 恢复数据
            backupMmkvDir.copyRecursively(mmkvDir, overwrite = true)
            
            // 重新初始化
            MMKV.initialize(context)
            
            true
        } catch (e: Exception) {
            Log.e("MMKVBackup", "恢复失败", e)
            false
        }
    }
    
    // 导出单个 MMKV 实例为 JSON
    fun exportToJson(mmkvId: String): String {
        val kv = MMKV.mmkvWithID(mmkvId)
        val allKeys = kv.allKeys() ?: return "{}"
        
        val map = mutableMapOf<String, Any?>()
        
        allKeys.forEach { key ->
            // 尝试各种类型（实际项目中应该有类型记录）
            map[key] = kv.decodeString(key, null)
                ?: kv.decodeInt(key, Int.MIN_VALUE).takeIf { it != Int.MIN_VALUE }
                ?: kv.decodeLong(key, Long.MIN_VALUE).takeIf { it != Long.MIN_VALUE }
                ?: kv.decodeBool(key, false)
        }
        
        return Gson().toJson(map)
    }
}
```

### 数据清理策略

```kotlin
// 定期清理过期数据
class MMKVCleaner(private val kv: MMKV) {
    
    companion object {
        private const val EXPIRE_SUFFIX = "_expire_at"
    }
    
    // 存储带过期时间的数据
    fun putWithExpire(key: String, value: String, expireMs: Long) {
        kv.encode(key, value)
        kv.encode("$key$EXPIRE_SUFFIX", System.currentTimeMillis() + expireMs)
    }
    
    // 获取数据（自动检查过期）
    fun get(key: String): String? {
        val expireAt = kv.decodeLong("$key$EXPIRE_SUFFIX", 0)
        
        if (expireAt > 0 && System.currentTimeMillis() > expireAt) {
            // 已过期，删除
            remove(key)
            return null
        }
        
        return kv.decodeString(key, null)
    }
    
    // 删除数据
    fun remove(key: String) {
        kv.removeValuesForKeys(arrayOf(key, "$key$EXPIRE_SUFFIX"))
    }
    
    // 清理所有过期数据
    fun cleanExpired() {
        val allKeys = kv.allKeys() ?: return
        val now = System.currentTimeMillis()
        
        val expiredKeys = mutableListOf<String>()
        
        allKeys.filter { it.endsWith(EXPIRE_SUFFIX) }.forEach { expireKey ->
            val expireAt = kv.decodeLong(expireKey, 0)
            if (expireAt > 0 && now > expireAt) {
                val dataKey = expireKey.removeSuffix(EXPIRE_SUFFIX)
                expiredKeys.add(dataKey)
                expiredKeys.add(expireKey)
            }
        }
        
        if (expiredKeys.isNotEmpty()) {
            kv.removeValuesForKeys(expiredKeys.toTypedArray())
            Log.d("MMKVCleaner", "清理了 ${expiredKeys.size / 2} 条过期数据")
        }
    }
}
```

```kotlin
// 使用 Kotlin 属性委托简化使用
class MMKVDelegate<T>(
    private val key: String,
    private val defaultValue: T,
    private val kv: MMKV = MMKV.defaultMMKV()
) : ReadWriteProperty<Any?, T> {
    
    @Suppress("UNCHECKED_CAST")
    override fun getValue(thisRef: Any?, property: KProperty<*>): T {
        return when (defaultValue) {
            is String -> kv.decodeString(key, defaultValue) as T
            is Int -> kv.decodeInt(key, defaultValue) as T
            is Long -> kv.decodeLong(key, defaultValue) as T
            is Float -> kv.decodeFloat(key, defaultValue) as T
            is Boolean -> kv.decodeBool(key, defaultValue) as T
            else -> throw IllegalArgumentException("Unsupported type")
        }
    }
    
    override fun setValue(thisRef: Any?, property: KProperty<*>, value: T) {
        when (value) {
            is String -> kv.encode(key, value)
            is Int -> kv.encode(key, value)
            is Long -> kv.encode(key, value)
            is Float -> kv.encode(key, value)
            is Boolean -> kv.encode(key, value)
            else -> throw IllegalArgumentException("Unsupported type")
        }
    }
}
```

## 面试检验

### 进阶概念题

**Q1：MMKV 如何支持多进程？原理是什么？**

> **答案**：MMKV 多进程支持基于两个机制：
> 1. **mmap 内存映射**：多进程可以同时映射同一个文件到各自的内存空间
> 2. **文件锁（flock）**：写入时加锁，保证互斥
> 3. **序列号机制**：每次写入更新序列号，其他进程读取时检查序列号变化，如果变了就重新加载
> 
> 使用方式：`MMKV.mmkvWithID("id", MMKV.MULTI_PROCESS_MODE)`

**Q2：从 SharedPreferences 迁移到 MMKV 有哪些注意事项？**

> **答案**：
> 1. **数据迁移**：使用 `importFromSharedPreferences()` 导入旧数据
> 2. **迁移标记**：记录迁移状态，避免重复迁移
> 3. **清理旧数据**：迁移后清空 SP，避免数据不一致
> 4. **默认值处理**：`decodeString` 可能返回 null，需要额外处理
> 5. **类型兼容**：SP 的 StringSet 和 MMKV 的 encode(Set) 可以兼容
> 6. **渐进式迁移**：大型项目可以逐步迁移，先迁移高频访问的数据

**Q3：MMKV 的加密安全吗？有什么限制？**

> **答案**：
> - **安全性**：MMKV 使用 AES-CFB 加密，算法本身是安全的
> - **密钥管理**：关键是密钥如何存储。建议使用 Android Keystore
> - **限制**：
>   1. 加密有性能损耗（约 5-10%）
>   2. 密钥长度建议 16 字节（AES-128）
>   3. 更换密钥需要调用 `reKey()` 方法
>   4. 不支持单个字段加密，整个文件要么加密要么不加密

**Q4：MMKV 和 DataStore 怎么选？**

> **答案**：
> | 场景 | 选择 |
> |-----|------|
> | 需要多进程 | MMKV（DataStore 不支持） |
> | 高频写入 | MMKV（mmap 性能更好） |
> | 纯协程项目 | DataStore（原生协程 API） |
> | 需要类型安全 | Proto DataStore |
> | 需要数据加密 | MMKV（内置支持） |
> | 简单配置存储 | 都可以 |

**Q5：MMKV 数据损坏怎么办？如何预防？**

> **答案**：
> **恢复机制**：
> - MMKV 有 CRC 校验，能检测数据损坏
> - 可以注册 `MMKVHandler` 处理异常情况
> - 提供 `OnErrorRecover` 策略，自动恢复可恢复的数据
> 
> **预防措施**：
> 1. 定期备份重要数据
> 2. 不存储过大的数据（单个文件建议 < 100MB）
> 3. 监控 CRC 校验失败的情况
> 4. 关键数据做版本管理，可以回滚
