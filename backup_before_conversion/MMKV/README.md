# MMKV 学习指南

## 概述

MMKV 是腾讯开源的一款**高性能**、**跨平台**的键值存储框架，基于 mmap 内存映射实现。它是 SharedPreferences 的终极替代方案，性能提升可达 **100 倍以上**。

> **一句话理解**：如果说 SharedPreferences 是用笔一字一句地写日记，MMKV 就是直接在脑子里想好、瞬间印到纸上——这就是内存映射的魔力。

## 为什么要学 MMKV？

| 场景 | SharedPreferences | MMKV |
|-----|-------------------|------|
| 写入速度 | 可能卡主线程（特别是 apply 堆积） | 微秒级，完全不卡 |
| 多进程 | 数据不同步，容易出 bug | 原生支持，数据实时同步 |
| 数据安全 | 明文存储 | 可选加密存储 |
| ANR 风险 | 高（commit 阻塞、apply 堆积） | 极低 |
| 大数据量 | 性能急剧下降 | 稳定如一 |

## 相关技术

| 技术 | 关系 | 说明 |
|-----|------|------|
| SharedPreferences | 被替代 | MMKV 是 SP 的高性能替代方案 |
| DataStore | 竞争 | Google 官方推出的 SP 替代方案，但性能不如 MMKV |
| SQLite/Room | 互补 | 复杂数据用数据库，简单键值用 MMKV |
| ProtoBuf | 依赖 | MMKV 内部使用 ProtoBuf 编码，高效紧凑 |
