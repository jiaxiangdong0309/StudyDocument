# ClassLoader 类加载机制

> 理解类加载，打通热修复和插件化的任督二脉

## 为什么要学类加载机制？

类加载机制是 Android 高级开发的**底层基石**：

| 技术方向 | 与类加载的关系 |
|---------|--------------|
| 热修复 | 修改 dexElements 加载顺序 |
| 插件化 | 自定义 ClassLoader 加载插件 |
| 加固脱壳 | 理解 dex 加载时机 |
| 性能优化 | 类加载耗时分析 |

**一句话**：不懂类加载，热修复和插件化就是「知其然不知其所以然」。
