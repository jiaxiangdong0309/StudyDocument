# 项目结构与配置文件详解 (Project Structure)

## 1. 解决什么问题？

> **一句话直击核心**：理解 Vite 项目的目录结构和配置文件，是高效开发的基础。

* **痛点**：不了解项目结构会导致文件放错位置、配置不生效等问题
* **作用**：掌握每个目录和文件的作用，能让你快速定位问题、合理组织代码

---

## 2. 通俗理解

### 核心定义

Vite 项目采用约定优于配置的理念，有一套清晰的目录结构。其中最重要的特点是：**`index.html` 位于项目根目录**，而不是像 Webpack 那样藏在 public 文件夹里。

### 生活化比喻

**Vite 项目结构就像一栋房子**：
- `index.html` 是大门（入口）
- `src/` 是各个房间（源代码）
- `public/` 是门口的装饰品（静态资源，原样输出）
- `vite.config.js` 是房屋设计图纸（构建配置）
- `node_modules/` 是仓库（依赖包）

---

## 3. 标准项目结构

```
my-vite-app/
├── node_modules/          # 依赖包目录
├── public/                # 静态资源目录（不经过构建处理）
│   └── favicon.ico        # 网站图标
├── src/                   # 源代码目录
│   ├── assets/            # 资源文件（会被构建处理）
│   │   └── logo.png
│   ├── components/        # 组件目录
│   │   └── HelloWorld.vue
│   ├── App.vue            # 根组件
│   ├── main.js            # 入口文件
│   └── style.css          # 全局样式
├── .gitignore             # Git 忽略配置
├── index.html             # 入口 HTML（重要！在根目录）
├── package.json           # 项目配置和依赖
├── vite.config.js         # Vite 配置文件
└── README.md              # 项目说明
```

## 4. 核心文件详解

### 4.1 index.html - 入口文件

**为什么 index.html 在根目录？**

Vite 将 `index.html` 视为源码的一部分，而不是静态资源。这样设计的好处：
- 开发时无需额外的服务器处理
- 可以直接在 HTML 中使用 ES Modules
- 支持 HTML 级别的热更新

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <!-- %PUBLIC_URL% 不需要了，直接写路径 -->
    <link rel="icon" type="image/svg+xml" href="/vite.svg" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Vite + Vue</title>
  </head>
  <body>
    <div id="app"></div>
    <!-- 关键：使用 type="module" 引入入口文件 -->
    <script type="module" src="/src/main.js"></script>
  </body>
</html>
```

**核心要点**：
- `type="module"` 告诉浏览器这是 ES Module
- `/src/main.js` 路径从项目根目录开始
- 可以在 HTML 中直接写多个 `<script type="module">`

### 4.2 src/main.js - 应用入口

```javascript
// Vue 3 项目的入口文件
import { createApp } from 'vue'
import App from './App.vue'
import './style.css'  // 直接导入 CSS

// 创建并挂载应用
createApp(App).mount('#app')
```

```javascript
// React 项目的入口文件
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App'
import './index.css'

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
)
```

### 4.3 public/ 与 src/assets/ 的区别

| 特性 | public/ | src/assets/ |
|-----|---------|-------------|
| 构建处理 | ❌ 不处理，原样复制 | ✅ 会被处理（压缩、hash等） |
| 引用方式 | 绝对路径 `/xxx` | 相对路径或别名 `@/assets/xxx` |
| 文件名 | 保持原名 | 添加 hash 指纹 |
| 适用场景 | favicon、robots.txt | 图片、字体、需要优化的资源 |

```javascript
// public/ 中的文件引用
<img src="/logo.png" />  // 直接用绝对路径

// src/assets/ 中的文件引用
import logo from '@/assets/logo.png'  // 导入后使用
<img :src="logo" />
```

### 4.4 vite.config.js - 核心配置文件

```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { resolve } from 'path'

// https://vitejs.dev/config/
export default defineConfig({
  // 插件配置
  plugins: [vue()],

  // 路径解析配置
  resolve: {
    alias: {
      '@': resolve(__dirname, 'src'),  // @ 指向 src 目录
    },
  },

  // 开发服务器配置
  server: {
    port: 3000,        // 端口号
    open: true,        // 自动打开浏览器
    host: true,        // 监听所有地址
  },

  // 构建配置
  build: {
    outDir: 'dist',    // 输出目录
    sourcemap: true,   // 生成 sourcemap
  },
})
```

**配置文件支持的格式**：
- `vite.config.js` - JavaScript
- `vite.config.ts` - TypeScript
- `vite.config.mjs` - ES Module
- `vite.config.cjs` - CommonJS

### 4.5 package.json - 项目配置

```json
{
  "name": "my-vite-app",
  "private": true,
  "version": "0.0.0",
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  },
  "dependencies": {
    "vue": "^3.4.0"
  },
  "devDependencies": {
    "@vitejs/plugin-vue": "^5.0.0",
    "vite": "^5.0.0"
  }
}
```

**关键字段解析**：

| 字段 | 作用 |
|-----|------|
| `"type": "module"` | 表示项目使用 ES Modules |
| `scripts.dev` | 启动开发服务器 |
| `scripts.build` | 构建生产版本 |
| `scripts.preview` | 预览生产构建结果 |

## 5. TypeScript 项目的额外文件

TypeScript 项目会多出几个配置文件：

```
my-vite-app/
├── ...
├── tsconfig.json          # TypeScript 主配置
├── tsconfig.node.json     # Node 环境的 TS 配置
├── env.d.ts               # 环境变量类型声明
└── vite-env.d.ts          # Vite 特定类型声明
```

### tsconfig.json 示例

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "useDefineForClassFields": true,
    "module": "ESNext",
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "skipLibCheck": true,

    /* 模块解析 */
    "moduleResolution": "bundler",
    "allowImportingTsExtensions": true,
    "resolveJsonModule": true,
    "isolatedModules": true,
    "noEmit": true,
    "jsx": "preserve",

    /* 严格模式 */
    "strict": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "noFallthroughCasesInSwitch": true,

    /* 路径别名 */
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"]
    }
  },
  "include": ["src/**/*.ts", "src/**/*.tsx", "src/**/*.vue"],
  "references": [{ "path": "./tsconfig.node.json" }]
}
```

### vite-env.d.ts

```typescript
/// <reference types="vite/client" />

// 声明 .vue 文件的类型
declare module '*.vue' {
  import type { DefineComponent } from 'vue'
  const component: DefineComponent<{}, {}, any>
  export default component
}

// 声明环境变量类型
interface ImportMetaEnv {
  readonly VITE_API_URL: string
  // 更多环境变量...
}

interface ImportMeta {
  readonly env: ImportMetaEnv
}
```

      '@components': resolve(__dirname, 'src/components'),

## 7. 常见问题与解决方案

### Q1：为什么改了 vite.config.js 不生效？

**原因**：配置文件修改后需要重启开发服务器。

```bash
# 停止服务器（Ctrl + C），然后重新启动
npm run dev
```

### Q2：路径别名在 VSCode 中没有提示？

**解决**：需要在 `jsconfig.json` 或 `tsconfig.json` 中配置 paths：

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"]
    }
  }
}
```

### Q3：public 文件夹里的资源 404？

**检查点**：
1. 路径是否以 `/` 开头（绝对路径）
2. 文件名大小写是否正确（Linux 区分大小写）
3. 文件是否真的放在 public 目录下

```html
<!-- ✅ 正确 -->
<img src="/images/logo.png" />

<!-- ❌ 错误 -->
<img src="images/logo.png" />
<img src="./public/images/logo.png" />
```

## 8. 扩展思考

### Vite 项目 vs Webpack 项目结构对比

| 特性 | Vite | Webpack (Vue CLI) |
|-----|------|-------------------|
| HTML 入口位置 | 根目录 | public/ |
| 配置文件 | vite.config.js | vue.config.js |
| 环境变量前缀 | VITE_ | VUE_APP_ |
| 模块系统 | ES Modules | CommonJS/ES Modules |
| 默认别名 | 需手动配置 | @ 已配置 |
