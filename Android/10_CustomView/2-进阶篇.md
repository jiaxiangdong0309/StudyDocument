# 自定义 View 进阶篇

## 高级绑制技巧

### 1. Path 路径

Path 就像一支笔的轨迹，你可以控制笔在哪里落下、往哪里走、在哪里抬起。

```kotlin
val path = Path().apply {
    moveTo(100f, 100f)          // 移动到起点（抬笔移动）
    lineTo(200f, 100f)          // 画直线到某点
    lineTo(200f, 200f)          // 继续画直线
    quadTo(250f, 250f, 300f, 200f)  // 二阶贝塞尔曲线
    cubicTo(350f, 150f, 400f, 250f, 450f, 200f)  // 三阶贝塞尔曲线
    close()                      // 闭合路径（连接起点和终点）
}

canvas.drawPath(path, paint)
```

**Path 的常用方法**：

| 方法 | 作用 | 类比 |
|-----|------|------|
| `moveTo(x, y)` | 移动到某点，不画线 | 抬笔移动 |
| `lineTo(x, y)` | 从当前点画直线到某点 | 落笔画直线 |
| `close()` | 闭合路径 | 连接终点和起点 |
| `addCircle()` | 添加圆形路径 | 画一个圆的轨迹 |
| `addRect()` | 添加矩形路径 | 画一个矩形的轨迹 |
| `addArc()` | 添加弧形路径 | 画一段弧线 |

**实战：画一个心形**：

```kotlin
class HeartView @JvmOverloads constructor(
    context: Context,
    attrs: AttributeSet? = null,
    defStyleAttr: Int = 0
) : View(context, attrs, defStyleAttr) {

    private val paint = Paint().apply {
        color = Color.RED
        isAntiAlias = true
        style = Paint.Style.FILL
    }
    
    private val path = Path()

    override fun onSizeChanged(w: Int, h: Int, oldw: Int, oldh: Int) {
        super.onSizeChanged(w, h, oldw, oldh)
        // 在这里计算路径，避免在 onDraw 中重复计算
        createHeartPath(w.toFloat(), h.toFloat())
    }
    
    private fun createHeartPath(width: Float, height: Float) {
        path.reset()
        
        // 心形的数学公式实现
        val centerX = width / 2
        val centerY = height / 2
        val scale = minOf(width, height) / 4
        
        path.moveTo(centerX, centerY + scale)  // 底部尖点
        
        // 左半边曲线
        path.cubicTo(
            centerX - scale * 2, centerY,        // 控制点1
            centerX - scale * 2, centerY - scale, // 控制点2
            centerX, centerY - scale * 0.5f      // 终点
        )
        
        // 右半边曲线
        path.cubicTo(
            centerX + scale * 2, centerY - scale, // 控制点1
            centerX + scale * 2, centerY,         // 控制点2
            centerX, centerY + scale              // 终点
        )
        
        path.close()
    }

    override fun onDraw(canvas: Canvas) {
        super.onDraw(canvas)
        canvas.drawPath(path, paint)
    }
}
```

### 2. 贝塞尔曲线

贝塞尔曲线是所有复杂曲线的基础。

**二阶贝塞尔曲线**（1个控制点）：

```
        控制点 P1
           /\
          /  \
         /    \
    起点 P0     终点 P2
```

```kotlin
// quadTo(controlX, controlY, endX, endY)
path.moveTo(p0x, p0y)
path.quadTo(p1x, p1y, p2x, p2y)
```

**三阶贝塞尔曲线**（2个控制点）：

```
            P1        P2
           /            \
          /              \
         /                \
    起点 P0                终点 P3
```

```kotlin
// cubicTo(control1X, control1Y, control2X, control2Y, endX, endY)
path.moveTo(p0x, p0y)
path.cubicTo(p1x, p1y, p2x, p2y, p3x, p3y)
```

**实战：波浪动画**：

```kotlin
class WaveView @JvmOverloads constructor(
    context: Context,
    attrs: AttributeSet? = null,
    defStyleAttr: Int = 0
) : View(context, attrs, defStyleAttr) {

    private val wavePaint = Paint().apply {
        color = Color.parseColor("#4FC3F7")
        isAntiAlias = true
        style = Paint.Style.FILL
    }
    
    private val wavePath = Path()
    
    // 波浪参数
    private var waveLength = 0f    // 波长（一个完整波浪的宽度）
    private var waveHeight = 50f   // 波高
    private var offset = 0f        // 水平偏移（用于动画）
    
    // 属性动画
    private val animator = ValueAnimator.ofFloat(0f, 1f).apply {
        duration = 2000
        repeatCount = ValueAnimator.INFINITE
        interpolator = LinearInterpolator()
        addUpdateListener { animation ->
            offset = animation.animatedValue as Float * waveLength
            invalidate()  // 触发重绘
        }
    }
    
    override fun onSizeChanged(w: Int, h: Int, oldw: Int, oldh: Int) {
        super.onSizeChanged(w, h, oldw, oldh)
        waveLength = w.toFloat()  // 波长等于 View 宽度
    }
    
    override fun onDraw(canvas: Canvas) {
        super.onDraw(canvas)
        
        wavePath.reset()
        
        // 起点在左边屏幕外（为了动画连续）
        wavePath.moveTo(-waveLength + offset, height / 2f)
        
        // 画多个波浪（保证覆盖整个屏幕）
        var x = -waveLength + offset
        while (x < width + waveLength) {
            // 用二阶贝塞尔画一个波峰
            wavePath.quadTo(
                x + waveLength / 4, height / 2f - waveHeight,  // 控制点（波峰）
                x + waveLength / 2, height / 2f               // 终点
            )
            // 再画一个波谷
            wavePath.quadTo(
                x + waveLength * 3 / 4, height / 2f + waveHeight,  // 控制点（波谷）
                x + waveLength, height / 2f                        // 终点
            )
            x += waveLength
        }
        
        // 闭合路径（画到底部再回来）
        wavePath.lineTo(width.toFloat(), height.toFloat())
        wavePath.lineTo(0f, height.toFloat())
        wavePath.close()
        
        canvas.drawPath(wavePath, wavePaint)
    }
    
    override fun onAttachedToWindow() {
        super.onAttachedToWindow()
        animator.start()
    }
    
    override fun onDetachedFromWindow() {
        super.onDetachedFromWindow()
        animator.cancel()
    }
}
```

### 3. Canvas 裁剪

用 `clipPath` 或 `clipRect` 可以裁剪画布，只在指定区域内绘制。

**实战：圆形头像**：

```kotlin
class CircleImageView @JvmOverloads constructor(
    context: Context,
    attrs: AttributeSet? = null,
    defStyleAttr: Int = 0
) : AppCompatImageView(context, attrs, defStyleAttr) {

    private val clipPath = Path()
    private val paint = Paint(Paint.ANTI_ALIAS_FLAG)
    
    // 边框画笔
    private val borderPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        style = Paint.Style.STROKE
        color = Color.WHITE
        strokeWidth = 4f
    }

    override fun onSizeChanged(w: Int, h: Int, oldw: Int, oldh: Int) {
        super.onSizeChanged(w, h, oldw, oldh)
        
        // 创建圆形裁剪路径
        val radius = minOf(w, h) / 2f
        clipPath.reset()
        clipPath.addCircle(w / 2f, h / 2f, radius, Path.Direction.CW)
    }

    override fun onDraw(canvas: Canvas) {
        // 保存画布状态
        canvas.save()
        
        // 裁剪成圆形
        canvas.clipPath(clipPath)
        
        // 绘制原始图片（会被裁剪成圆形）
        super.onDraw(canvas)
        
        // 恢复画布状态
        canvas.restore()
        
        // 画边框（在裁剪区域外画）
        val radius = minOf(width, height) / 2f - borderPaint.strokeWidth / 2
        canvas.drawCircle(width / 2f, height / 2f, radius, borderPaint)
    }
}
```

> **更好的方案**：使用 `BitmapShader` 或者直接用 `Glide/Coil` 的圆形变换，性能更好。

### 4. 图层 Layer

`saveLayer` 可以创建一个离屏缓冲区，用于实现特殊效果。

```kotlin
// 创建图层
val layerId = canvas.saveLayer(0f, 0f, width.toFloat(), height.toFloat(), null)

// 在图层上绘制...
canvas.drawXxx(...)

// 设置 Xfermode（混合模式）
paint.xfermode = PorterDuffXfermode(PorterDuff.Mode.SRC_IN)
canvas.drawXxx(...)

// 清除 Xfermode
paint.xfermode = null

// 恢复图层（会把图层合并到主画布）
canvas.restoreToCount(layerId)
```

**常用的 Xfermode**：

| 模式 | 效果 | 用途 |
|-----|------|------|
| SRC_IN | 只显示源图像与目标重叠的部分 | 圆形头像 |
| DST_IN | 只显示目标图像与源重叠的部分 | 蒙版效果 |
| SRC_OVER | 源图像覆盖在目标上 | 叠加效果 |
| XOR | 只显示不重叠的部分 | 刮刮卡效果 |

**实战：刮刮卡效果**：

```kotlin
class ScratchCardView @JvmOverloads constructor(
    context: Context,
    attrs: AttributeSet? = null,
    defStyleAttr: Int = 0
) : View(context, attrs, defStyleAttr) {

    // 底层图片（奖品）
    private lateinit var prizeBitmap: Bitmap
    // 遮罩层（涂层）
    private lateinit var maskBitmap: Bitmap
    private lateinit var maskCanvas: Canvas
    
    // 刮开的画笔
    private val erasePaint = Paint().apply {
        isAntiAlias = true
        style = Paint.Style.STROKE
        strokeWidth = 80f
        strokeCap = Paint.Cap.ROUND  // 圆头
        xfermode = PorterDuffXfermode(PorterDuff.Mode.CLEAR)  // 清除模式
    }
    
    private val drawPaint = Paint()
    private val scratchPath = Path()
    private var lastX = 0f
    private var lastY = 0f

    override fun onSizeChanged(w: Int, h: Int, oldw: Int, oldh: Int) {
        super.onSizeChanged(w, h, oldw, oldh)
        
        // 创建底层奖品图片（这里用纯色代替，实际应该加载图片）
        prizeBitmap = Bitmap.createBitmap(w, h, Bitmap.Config.ARGB_8888).apply {
            Canvas(this).drawColor(Color.parseColor("#FFD700"))  // 金色背景
        }
        
        // 创建遮罩层
        maskBitmap = Bitmap.createBitmap(w, h, Bitmap.Config.ARGB_8888)
        maskCanvas = Canvas(maskBitmap)
        maskCanvas.drawColor(Color.GRAY)  // 灰色涂层
    }

    override fun onTouchEvent(event: MotionEvent): Boolean {
        when (event.action) {
            MotionEvent.ACTION_DOWN -> {
                scratchPath.reset()
                scratchPath.moveTo(event.x, event.y)
                lastX = event.x
                lastY = event.y
            }
            MotionEvent.ACTION_MOVE -> {
                // 使用贝塞尔曲线让轨迹更平滑
                scratchPath.quadTo(lastX, lastY, (lastX + event.x) / 2, (lastY + event.y) / 2)
                lastX = event.x
                lastY = event.y
                
                // 在遮罩层上"擦除"
                maskCanvas.drawPath(scratchPath, erasePaint)
                invalidate()
            }
        }
        return true
    }

    override fun onDraw(canvas: Canvas) {
        super.onDraw(canvas)
        
        // 1. 先画底层奖品
        canvas.drawBitmap(prizeBitmap, 0f, 0f, drawPaint)
        
        // 2. 再画遮罩层（被擦除的部分是透明的，会露出底层）
        canvas.drawBitmap(maskBitmap, 0f, 0f, drawPaint)
    }
}
```

override fun onTouchEvent(event: MotionEvent): Boolean {

            // 手指抬起

            // 事件被拦截
        }
    }

### VelocityTracker：速度追踪

```kotlin
class FlingView @JvmOverloads constructor(
    context: Context,
    attrs: AttributeSet? = null,
    defStyleAttr: Int = 0
) : View(context, attrs, defStyleAttr) {

    private var velocityTracker: VelocityTracker? = null

    override fun onTouchEvent(event: MotionEvent): Boolean {
        // 初始化速度追踪器
        if (velocityTracker == null) {
            velocityTracker = VelocityTracker.obtain()
        }
        velocityTracker?.addMovement(event)
        
        when (event.action) {
            MotionEvent.ACTION_UP -> {
                // 计算速度（单位：像素/秒）
                velocityTracker?.computeCurrentVelocity(1000)  // 1000ms = 1s
                val velocityX = velocityTracker?.xVelocity ?: 0f
                val velocityY = velocityTracker?.yVelocity ?: 0f
                
                // 根据速度做 fling 动画...
                
                // 回收
                velocityTracker?.recycle()
                velocityTracker = null
            }
        }
        return true
    }
}
```

### Scroller：平滑滚动

```kotlin
class ScrollableView @JvmOverloads constructor(
    context: Context,
    attrs: AttributeSet? = null,
    defStyleAttr: Int = 0
) : View(context, attrs, defStyleAttr) {

    private val scroller = Scroller(context)

    // 开始滚动
    fun smoothScrollTo(destX: Int, destY: Int) {
        val startX = scrollX
        val startY = scrollY
        val deltaX = destX - startX
        val deltaY = destY - startY
        
        // 在 1000ms 内滚动到目标位置
        scroller.startScroll(startX, startY, deltaX, deltaY, 1000)
        invalidate()  // 触发绘制
    }

    override fun computeScroll() {
        // 判断滚动是否结束
        if (scroller.computeScrollOffset()) {
            // 滚动中，更新位置
            scrollTo(scroller.currX, scroller.currY)
            postInvalidateOnAnimation()  // 继续下一帧
        }
    }
}
```

## 性能优化

### 1. 减少 onDraw 的工作量

```kotlin
// ❌ 不好：每次绘制都重新计算
override fun onDraw(canvas: Canvas) {
    val path = Path()
    for (point in points) {
        // 复杂计算...
    }
    canvas.drawPath(path, paint)
}

// ✅ 好的：数据变化时才重新计算
private val path = Path()

private fun updatePath() {
    path.reset()
    for (point in points) {
        // 复杂计算...
    }
}

fun setPoints(newPoints: List<Point>) {
    points = newPoints
    updatePath()  // 只在数据变化时计算
    invalidate()
}

override fun onDraw(canvas: Canvas) {
    canvas.drawPath(path, paint)  // 直接画
}
```

### 2. 使用硬件加速

```kotlin
// 代码中开启（针对单个 View）
view.setLayerType(View.LAYER_TYPE_HARDWARE, null)

// 代码中关闭（某些绘制不支持硬件加速）
view.setLayerType(View.LAYER_TYPE_SOFTWARE, null)
```

**硬件加速不支持的操作**：

| 不支持的操作 | 替代方案 |
|------------|---------|
| `Canvas.clipPath()` (API < 18) | 使用 `PorterDuffXfermode` |
| `Paint.setShadowLayer()` (部分) | 使用 `elevation` |
| 某些 `Xfermode` | 使用 `saveLayer` |

### 3. 避免过度绘制

```kotlin
// ❌ 不好：先画背景，再画内容，背景被覆盖了（过度绘制）
override fun onDraw(canvas: Canvas) {
    canvas.drawColor(Color.WHITE)      // 画背景
    canvas.drawRect(rect, paint)       // 画矩形（覆盖了部分背景）
}

// ✅ 好的：只画需要的部分
override fun onDraw(canvas: Canvas) {
    // 如果内容会覆盖整个区域，就不需要画背景
    canvas.drawRect(rect, paint)
}
```

### 4. 使用 invalidate(Rect) 局部刷新

```kotlin
// ❌ 不好：整个 View 重绘
invalidate()

// ✅ 好的：只重绘变化的区域
invalidate(dirtyRect)
```

### 5. 复用对象

```kotlin
// ❌ 不好：每次都创建新对象
override fun onDraw(canvas: Canvas) {
    val rect = Rect(0, 0, width, height)
    canvas.drawRect(rect, paint)
}

// ✅ 好的：复用对象
private val rect = Rect()

override fun onDraw(canvas: Canvas) {
    rect.set(0, 0, width, height)
    canvas.drawRect(rect, paint)
}
```

## 实战案例：环形进度条

```kotlin
/**
 * 环形进度条
 * 
 * 特性：
 * - 渐变色
 * - 圆角端点
 * - 动画效果
 * - 中间显示百分比
 */
class CircleProgressView @JvmOverloads constructor(
    context: Context,
    attrs: AttributeSet? = null,
    defStyleAttr: Int = 0
) : View(context, attrs, defStyleAttr) {

    // 进度（0-100）
    var progress: Int = 0
        set(value) {
            field = value.coerceIn(0, 100)
            invalidate()
        }

    // 背景环画笔
    private val bgPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        style = Paint.Style.STROKE
        strokeWidth = 30f
        color = Color.parseColor("#E0E0E0")
    }

    // 进度环画笔
    private val progressPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        style = Paint.Style.STROKE
        strokeWidth = 30f
        strokeCap = Paint.Cap.ROUND  // 圆角端点
    }

    // 文字画笔
    private val textPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        color = Color.BLACK
        textSize = 60f
        textAlign = Paint.Align.CENTER
    }

    // 绘制区域
    private val rectF = RectF()
    
    // 渐变色
    private var gradient: SweepGradient? = null

    override fun onSizeChanged(w: Int, h: Int, oldw: Int, oldh: Int) {
        super.onSizeChanged(w, h, oldw, oldh)
        
        // 计算绘制区域（正方形，考虑 padding 和线宽）
        val strokeWidth = progressPaint.strokeWidth
        val padding = strokeWidth / 2
        val size = minOf(w - paddingLeft - paddingRight, h - paddingTop - paddingBottom)
        val left = paddingLeft + (w - paddingLeft - paddingRight - size) / 2f + padding
        val top = paddingTop + (h - paddingTop - paddingBottom - size) / 2f + padding
        rectF.set(left, top, left + size - strokeWidth, top + size - strokeWidth)
        
        // 创建渐变色
        val centerX = rectF.centerX()
        val centerY = rectF.centerY()
        gradient = SweepGradient(
            centerX, centerY,
            intArrayOf(
                Color.parseColor("#FF6B6B"),  // 红
                Color.parseColor("#FFE66D"),  // 黄
                Color.parseColor("#4ECDC4"),  // 青
                Color.parseColor("#6C5CE7"),  // 紫
                Color.parseColor("#FF6B6B")   // 回到红（闭环）
            ),
            null
        )
        progressPaint.shader = gradient
    }

    override fun onDraw(canvas: Canvas) {
        super.onDraw(canvas)
        
        // 1. 画背景环
        canvas.drawArc(rectF, 0f, 360f, false, bgPaint)
        
        // 2. 画进度环（从顶部开始，即 -90 度）
        val sweepAngle = progress / 100f * 360
        canvas.drawArc(rectF, -90f, sweepAngle, false, progressPaint)
        
        // 3. 画百分比文字
        val text = "$progress%"
        // 计算文字基线位置（让文字垂直居中）
        val textY = rectF.centerY() - (textPaint.descent() + textPaint.ascent()) / 2
        canvas.drawText(text, rectF.centerX(), textY, textPaint)
    }

    /**
     * 动画设置进度
     */
    fun animateProgress(targetProgress: Int, duration: Long = 1000) {
        ValueAnimator.ofInt(progress, targetProgress).apply {
            this.duration = duration
            interpolator = DecelerateInterpolator()
            addUpdateListener { animation ->
                progress = animation.animatedValue as Int
            }
            start()
        }
    }
}
```

**使用**：

```kotlin
circleProgressView.animateProgress(75)  // 动画到 75%
```

## 横向对比

### 自定义 View vs Drawable vs Compose

| 方案 | 优点 | 缺点 | 适用场景 |
|-----|------|------|---------|
| **自定义 View** | 功能强大、支持事件 | 代码量大、学习成本高 | 复杂交互控件 |
| **自定义 Drawable** | 轻量、可复用 | 不支持事件 | 静态图形、背景 |
| **Compose Canvas** | 声明式、简洁 | 需要 Compose 环境 | 新项目、Compose UI |

### 什么时候不该自定义 View？

1. **能用现有控件组合实现**：先试试 ConstraintLayout + 现有控件
2. **只是换个颜色/形状**：用 Drawable 或 Shape XML
3. **简单的列表/网格**：用 RecyclerView + ItemDecoration
4. **图表类需求**：考虑 MPAndroidChart 等成熟库

## 小结

| 内容 | 要点 |
|-----|------|
| Path | 描述轨迹，moveTo、lineTo、quadTo、cubicTo |
| 贝塞尔曲线 | 二阶（1个控制点）、三阶（2个控制点） |
| Canvas 裁剪 | clipPath、clipRect |
| 图层 | saveLayer + Xfermode 实现特殊效果 |
| 手势检测 | GestureDetector、VelocityTracker |
| 平滑滚动 | Scroller + computeScroll |
| 性能优化 | 复用对象、减少计算、局部刷新 |

## 面试题检验

### Q1：贝塞尔曲线的原理？二阶和三阶有什么区别？

**结论**：贝塞尔曲线通过控制点来定义曲线形状。二阶有1个控制点，三阶有2个控制点。

**原理**：贝塞尔曲线是通过线性插值计算的。以二阶为例，在起点 P0 和控制点 P1 之间取一点 Q0，在 P1 和终点 P2 之间取一点 Q1，再在 Q0 和 Q1 之间取一点，这个点的轨迹就是贝塞尔曲线。

**区别**：
- 二阶：曲线形状简单，只能形成单弯
- 三阶：曲线形状复杂，可以形成 S 形等复杂曲线

---

### Q2：PorterDuff.Mode 是什么？常用的模式有哪些？

**结论**：PorterDuff.Mode 定义了两个图像如何混合。

**常用模式**：
- `SRC_IN`：只保留源图像与目标重叠的部分（圆形头像）
- `DST_IN`：只保留目标图像与源重叠的部分（蒙版）
- `CLEAR`：清除（刮刮卡）
- `XOR`：只保留不重叠的部分

---

### Q3：GestureDetector 能检测哪些手势？

**结论**：单击、双击、长按、滑动、快速滑动（fling）。

**区分**：
- `onSingleTapUp`：单击抬起（可能是双击的第一次）
- `onSingleTapConfirmed`：确认单击（300ms 后确认不是双击）
- `onScroll`：手指在屏幕上移动
- `onFling`：手指快速滑动后抬起

---

### Q4：Scroller 的工作原理？为什么 View.scrollTo 不是平滑滚动？

**结论**：`scrollTo` 是瞬间移动，`Scroller` 通过计算每一帧的位置实现平滑滚动。

**原理**：
1. `Scroller.startScroll()` 只是记录起点、终点、时长，不会触发滚动
2. 调用 `invalidate()` 触发 `draw()`，`draw()` 会调用 `computeScroll()`
3. 在 `computeScroll()` 中调用 `scroller.computeScrollOffset()` 计算当前位置
4. 用 `scrollTo()` 移动到计算出的位置
5. 调用 `postInvalidateOnAnimation()` 继续下一帧

---

### Q5：自定义 View 有哪些性能优化手段？

**结论**：

1. **减少 onDraw 工作量**：复杂计算移到 onSizeChanged 或数据变化时
2. **复用对象**：Paint、Path、Rect 等在构造函数中创建
3. **局部刷新**：使用 `invalidate(Rect)` 而非 `invalidate()`
4. **避免过度绘制**：不画被覆盖的区域
5. **硬件加速**：利用 GPU 加速绑制
6. **减少图层**：少用 `saveLayer`，它会创建离屏缓冲区

---

### Q6：invalidate() 和 postInvalidate() 的区别？

**结论**：`invalidate()` 只能在主线程调用，`postInvalidate()` 可以在任意线程调用。

**原理**：`postInvalidate()` 内部通过 Handler 把 `invalidate()` 调用 post 到主线程。

---

### Q7：如何实现一个圆形头像？有几种方案？

**结论**：

1. **clipPath**：简单，但有锯齿（API < 18）
2. **BitmapShader**：性能好，无锯齿
3. **Xfermode**：灵活，可做复杂效果
4. **CardView + clipToOutline**：最简单
5. **Glide/Coil 变换**：最推荐，省心省力

---

### Q8：手势检测中，如何区分单击和双击？

**结论**：使用 `onSingleTapConfirmed` 和 `onDoubleTap`。

**原理**：系统会等待约 300ms，如果期间有第二次点击就触发 `onDoubleTap`，否则触发 `onSingleTapConfirmed`。

**注意**：如果用 `onSingleTapUp`，双击时会触发两次（每次抬起都会触发）。
