# 数字雨效果实战（Matrix Rain Effect）

## 效果预览

就是《黑客帝国》里那个经典的绿色数字从上往下流动的效果：

```
┌────────────────────────────┐
│ 0  ア  1  カ  9  ウ  3  エ │  ← 不同列独立下落
│ 1  イ  0  キ  2  オ  7  ア │
│ █  ウ  █  ク  █  カ  █  イ │  ← █ 表示最亮的"头部"
│ 0  エ  1  ケ  8  キ  1  ウ │
│ 9  オ  0  コ  3  ク  4  エ │  ← 越往上越暗（尾迹效果）
│    カ     サ     ケ     オ │
│    キ        　  コ        │
└────────────────────────────┘
```

## 实现思路

### 核心问题拆解

实现数字雨需要解决几个问题：

| 问题 | 解决方案 |
|-----|---------|
| 多列独立下落 | 每列维护自己的 y 坐标和速度 |
| 字符随机变化 | 使用随机字符集，定时更换 |
| 头亮尾暗效果 | 根据位置设置不同透明度 |
| 流畅动画 | 使用 `invalidate()` 循环刷新 |

### 数据结构设计

```
每一列（Column）需要记录：
┌─────────────────────────┐
│  y：当前头部的 y 坐标    │
│  speed：下落速度         │
│  chars：这一列的字符数组  │
│  length：尾迹长度        │
└─────────────────────────┘
```

## 分步实现

### 第一步：定义数据类

```kotlin
/**
 * 数字雨中的一列
 * @param x 这一列的 x 坐标
 * @param y 头部字符的 y 坐标（会不断增加）
 * @param speed 下落速度（像素/帧）
 * @param length 尾迹长度（显示多少个字符）
 */
data class RainColumn(
    val x: Float,
    var y: Float,
    val speed: Float,
    val length: Int
)
```

### 第二步：基础框架

```kotlin
class MatrixRainView @JvmOverloads constructor(
    context: Context,
    attrs: AttributeSet? = null,
    defStyleAttr: Int = 0
) : View(context, attrs, defStyleAttr) {

    // ========== 配置参数 ==========
    private val textSize = 14.sp          // 字符大小
    private val columnSpacing = 20.sp     // 列间距
    private val primaryColor = Color.GREEN // 主色调

    // ========== 字符集 ==========
    // 数字 + 片假名，营造科技感
    private val charset = "0123456789アイウエオカキクケコサシスセソタチツテトナニヌネノ"

    // ========== 绘制相关 ==========
    private val paint = Paint().apply {
        color = primaryColor
        textSize = this@MatrixRainView.textSize
        isAntiAlias = true
        typeface = Typeface.MONOSPACE  // 等宽字体，保证对齐
    }

    // ========== 雨滴数据 ==========
    private val columns = mutableListOf<RainColumn>()
    private val random = Random()

    // ========== 控制参数 ==========
    private var isRunning = false

    // sp 转 px 扩展
    private val Int.sp: Float
        get() = this * resources.displayMetrics.scaledDensity
}
```

### 第三步：初始化雨滴列

```kotlin
override fun onSizeChanged(w: Int, h: Int, oldw: Int, oldh: Int) {
    super.onSizeChanged(w, h, oldw, oldh)
    initColumns()
}

/**
 * 根据 View 宽度，计算需要多少列，并初始化每列数据
 */
private fun initColumns() {
    columns.clear()

    // 计算列数：View 宽度 / 列间距
    val columnCount = (width / columnSpacing).toInt()

    for (i in 0 until columnCount) {
        columns.add(createColumn(i))
    }
}

/**
 * 创建一列雨滴
 * @param index 第几列
 */
private fun createColumn(index: Int): RainColumn {
    return RainColumn(
        x = index * columnSpacing,
        // y 初始值随机，让各列错开，避免同时出现
        y = -random.nextInt(height).toFloat(),
        // 速度随机，让动画更自然
        speed = 5f + random.nextFloat() * 10f,
        // 尾迹长度随机
        length = 10 + random.nextInt(15)
    )
}
```

### 第四步：核心绘制逻辑

```kotlin
override fun onDraw(canvas: Canvas) {
    super.onDraw(canvas)

    // 绘制黑色背景
    canvas.drawColor(Color.BLACK)

    // 绘制每一列
    for (column in columns) {
        drawColumn(canvas, column)
    }

    // 更新位置，准备下一帧
    updateColumns()

    // 持续刷新（约 60fps）
    if (isRunning) {
        postInvalidateDelayed(16)  // 16ms ≈ 60fps
    }
}

/**
 * 绘制一列字符
 * 核心：从头部往上绘制，越往上透明度越低
 */
private fun drawColumn(canvas: Canvas, column: RainColumn) {
    // 从头部位置开始，往上绘制 length 个字符
    for (i in 0 until column.length) {
        // 计算这个字符的 y 坐标（头部在下，尾部在上）
        val charY = column.y - i * textSize

        // 超出屏幕范围就不绘制
        if (charY < 0 || charY > height + textSize) continue

        // 计算透明度：头部最亮（255），尾部逐渐变暗
        val alpha = when (i) {
            0 -> 255                                    // 头部：全亮（白色闪光效果）
            1 -> 230                                    // 次头部：略暗
            else -> (255 * (1 - i.toFloat() / column.length)).toInt().coerceIn(0, 255)
        }

        // 头部用白色，其他用绿色
        paint.color = if (i == 0) Color.WHITE else primaryColor
        paint.alpha = alpha

        // 随机选一个字符绘制
        val char = charset[random.nextInt(charset.length)]
        canvas.drawText(char.toString(), column.x, charY, paint)
    }
}

/**
 * 更新每列的位置
 */
private fun updateColumns() {
    for ((index, column) in columns.withIndex()) {
        // y 坐标增加（往下移动）
        column.y += column.speed

        // 如果整列都超出屏幕底部，重置到顶部
        if (column.y - column.length * textSize > height) {
            columns[index] = createColumn(index)
        }
    }
}
```

### 第五步：生命周期控制

```kotlin
    super.onVisibilityChanged(changedView, visibility)
    if (visibility == VISIBLE) {
        start()
    } else {
        stop()
    }
}
```

## 完整代码

```kotlin
package com.example.customview

import android.content.Context
import android.graphics.Canvas
import android.graphics.Color
import android.graphics.Paint
import android.graphics.Typeface
import android.util.AttributeSet
import android.view.View
import kotlin.random.Random

/**
 * 数字雨效果（黑客帝国风格）
 *
 * 使用方式：
 * 1. XML 中添加：<com.example.customview.MatrixRainView ... />
 * 2. 代码中调用 start() 开始动画，stop() 停止动画
 */
class MatrixRainView @JvmOverloads constructor(
    context: Context,
    attrs: AttributeSet? = null,
    defStyleAttr: Int = 0
) : View(context, attrs, defStyleAttr) {

    // ==================== 数据类 ====================

    /**
     * 雨滴列
     */
    private data class RainColumn(
        val x: Float,          // x 坐标
        var y: Float,          // 头部 y 坐标
        val speed: Float,      // 下落速度
        val length: Int        // 尾迹长度
    )

    // ==================== 配置参数 ====================

    /** 字符大小 */
    var textSizeSp: Float = 14f
        set(value) {
            field = value
            paint.textSize = value.sp
            initColumns()
            invalidate()
        }

    /** 列间距 */
    var columnSpacingSp: Float = 20f
        set(value) {
            field = value
            initColumns()
            invalidate()
        }

    /** 主颜色 */
    var primaryColor: Int = Color.GREEN
        set(value) {
            field = value
            invalidate()
        }

    /** 背景颜色 */
    var backgroundColor: Int = Color.BLACK
        set(value) {
            field = value
            invalidate()
        }

    // ==================== 字符集 ====================

    private val charset = "0123456789アイウエオカキクケコサシスセソタチツテトナニヌネノハヒフヘホマミムメモヤユヨラリルレロワヲン"

    // ==================== 绘制相关 ====================

    private val paint = Paint().apply {
        textSize = textSizeSp.sp
        isAntiAlias = true
        typeface = Typeface.MONOSPACE
    }

    private val columns = mutableListOf<RainColumn>()
    private val random = Random

    private var isRunning = false

    // ==================== 扩展函数 ====================

    private val Float.sp: Float
        get() = this * resources.displayMetrics.scaledDensity

    // ==================== 初始化 ====================

    override fun onSizeChanged(w: Int, h: Int, oldw: Int, oldh: Int) {
        super.onSizeChanged(w, h, oldw, oldh)
        if (w > 0 && h > 0) {
            initColumns()
        }
    }

    private fun initColumns() {
        columns.clear()
        if (width <= 0) return

        val spacing = columnSpacingSp.sp
        val columnCount = (width / spacing).toInt()

        for (i in 0 until columnCount) {
            columns.add(createColumn(i, spacing))
        }
    }

    private fun createColumn(index: Int, spacing: Float): RainColumn {
        return RainColumn(
            x = index * spacing,
            y = -random.nextInt(maxOf(1, height)).toFloat(),
            speed = 5f + random.nextFloat() * 10f,
            length = 10 + random.nextInt(15)
        )
    }

    // ==================== 绑制 ====================

    override fun onDraw(canvas: Canvas) {
        super.onDraw(canvas)

        // 绘制背景
        canvas.drawColor(backgroundColor)

        val charSize = textSizeSp.sp

        // 绘制每一列
        for (column in columns) {
            drawColumn(canvas, column, charSize)
        }

        // 更新位置
        updateColumns(charSize)

        // 持续刷新
        if (isRunning) {
            postInvalidateDelayed(16)
        }
    }

    private fun drawColumn(canvas: Canvas, column: RainColumn, charSize: Float) {
        for (i in 0 until column.length) {
            val charY = column.y - i * charSize

            // 超出范围不绘制
            if (charY < -charSize || charY > height + charSize) continue

            // 计算透明度
            val alpha = when (i) {
                0 -> 255
                1 -> 230
                else -> (255 * (1 - i.toFloat() / column.length)).toInt().coerceIn(30, 255)
            }

            // 设置颜色：头部白色闪光，其他绿色渐变
            paint.color = if (i == 0) Color.WHITE else primaryColor
            paint.alpha = alpha

            // 随机字符
            val char = charset[random.nextInt(charset.length)]
            canvas.drawText(char.toString(), column.x, charY, paint)
        }
    }

    private fun updateColumns(charSize: Float) {
        val spacing = columnSpacingSp.sp
        for ((index, column) in columns.withIndex()) {
            column.y += column.speed

            // 超出底部，重置
            if (column.y - column.length * charSize > height) {
                columns[index] = createColumn(index, spacing)
            }
        }
    }

    // ==================== 生命周期控制 ====================

    fun start() {
        if (!isRunning) {
            isRunning = true
            invalidate()
        }
    }

    fun stop() {
        isRunning = false
    }

    override fun onDetachedFromWindow() {
        super.onDetachedFromWindow()
        stop()
    }

    override fun onVisibilityChanged(changedView: View, visibility: Int) {
        super.onVisibilityChanged(changedView, visibility)
        if (visibility == VISIBLE) {
            start()
        } else {
            stop()
        }
    }

    override fun onWindowFocusChanged(hasWindowFocus: Boolean) {
        super.onWindowFocusChanged(hasWindowFocus)
        if (hasWindowFocus) start() else stop()
    }
}
```

## 性能优化

### 已应用的优化

| 优化点 | 做法 | 原因 |
|-------|------|------|
| 避免 onDraw 创建对象 | Paint 在构造函数初始化 | onDraw 每秒调用 60 次，频繁创建对象会触发 GC |
| 跳过屏幕外绘制 | 判断 charY 是否在可见范围 | 减少无意义的绑制调用 |
| 及时停止动画 | onDetachedFromWindow 中 stop | 避免内存泄漏和 CPU 空转 |
| 使用 postInvalidateDelayed | 替代 Handler + Runnable | 更简洁，自动绑定 View 生命周期 |

### 进一步优化方向


```
│                    数字雨实现原理                         │

│                                                         │
```

## 面试延伸

**Q：如果数字雨效果卡顿，你会如何排查和优化？**

**排查思路**：
1. 用 Profiler 看 CPU 和内存，确认是 GPU 还是 CPU 瓶颈
2. 检查 onDraw 中是否有对象创建（打开 StrictMode）
3. 看绘制的字符数量是否过多

**优化方案**：
1. 减少列数或尾迹长度
2. 使用 SurfaceView 独立线程绘制
3. 开启硬件加速
4. 降低刷新率（30fps 通常够用）
5. 预计算字符，避免每帧 random
