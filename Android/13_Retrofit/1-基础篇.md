# Retrofit 基础篇

> 让网络请求变得像调用本地方法一样简单

## 技术演进：为什么需要 Retrofit？

### 原始时代：HttpURLConnection

在 Android 早期，网络请求是这样的：

```kotlin
// 😱 噩梦般的代码
fun fetchUser(): String {
    var connection: HttpURLConnection? = null
    var reader: BufferedReader? = null
    try {
        val url = URL("https://api.example.com/user")
        connection = url.openConnection() as HttpURLConnection
        connection.requestMethod = "GET"
        connection.connectTimeout = 10000
        connection.readTimeout = 10000

        val inputStream = connection.inputStream
        reader = BufferedReader(InputStreamReader(inputStream))
        val response = StringBuilder()
        var line: String?
        while (reader.readLine().also { line = it } != null) {
            response.append(line)
        }
        // 还要手动解析 JSON...
        return response.toString()
    } finally {
        reader?.close()
        connection?.disconnect()
    }
}
```

**问题**：代码冗长、容易出错、每个接口都要写一遍。

### 进化：OkHttp 时代

OkHttp 简化了很多，但仍然需要：

```kotlin
// 🤔 好了一点，但还是有点繁琐
val client = OkHttpClient()
val request = Request.Builder()
    .url("https://api.example.com/user")
    .build()

client.newCall(request).enqueue(object : Callback {
    override fun onResponse(call: Call, response: Response) {
        val json = response.body?.string()
        // 手动解析 JSON 成对象
        val user = Gson().fromJson(json, User::class.java)
    }
    override fun onFailure(call: Call, e: IOException) { }
})
```

**问题**：每次都要构建 Request、手动解析响应、类型不安全。

### 现代：Retrofit 时代

```kotlin
// ✨ 优雅！
interface ApiService {
    @GET("user")
    suspend fun getUser(): User  // 直接返回对象！
}

// 使用
val user = apiService.getUser()
```

**Retrofit 的核心理念**：用声明式的方式定义 API，让框架帮你处理所有脏活累活。

## 核心概念

### 一句话理解

| 概念 | 大白话解释 |
|-----|----------|
| **Retrofit** | 翻译官，把接口定义翻译成 HTTP 请求 |
| **接口定义** | 菜单，告诉翻译官你想要什么 |
| **Converter** | 包装工，把 JSON 变成对象、对象变成 JSON |
| **CallAdapter** | 适配器，让结果变成你想要的类型（RxJava、协程等） |
| **OkHttp** | 快递员，真正负责发送和接收 |

### 工作流程

```mermaid
graph LR
    A[定义接口] --> B[Retrofit 创建代理]
    B --> C[调用接口方法]
    C --> D[解析注解]
    D --> E[构建 OkHttp Request]
    E --> F[OkHttp 发送请求]
    F --> G[接收 Response]
    G --> H[Converter 转换]
    H --> I[返回结果对象]

```

## 快速开始

### 1. 添加依赖

```kotlin
// build.gradle.kts
dependencies {
    implementation("com.squareup.retrofit2:retrofit:2.9.0")
    implementation("com.squareup.retrofit2:converter-gson:2.9.0")
}
```

### 2. 定义数据类

```kotlin
// 响应数据模型
data class User(
    val id: Int,
    val name: String,
    val email: String
)

data class Post(
    val id: Int,
    val title: String,
    val body: String,
    val userId: Int
)
```

### 3. 定义 API 接口

```kotlin
interface ApiService {
    // GET 请求
    @GET("users/{id}")
    suspend fun getUser(@Path("id") userId: Int): User

    // GET 带查询参数
    @GET("posts")
    suspend fun getPosts(@Query("userId") userId: Int): List<Post>

    // POST 请求
    @POST("posts")
    suspend fun createPost(@Body post: Post): Post
}
```

### 4. 创建 Retrofit 实例

```kotlin
object RetrofitClient {
    private const val BASE_URL = "https://jsonplaceholder.typicode.com/"

    val apiService: ApiService by lazy {
        Retrofit.Builder()
            .baseUrl(BASE_URL)
            // 添加 Gson 转换器，自动把 JSON 转成对象
            .addConverterFactory(GsonConverterFactory.create())
            .build()
            .create(ApiService::class.java)
    }
}
```

### 5. 发起请求

```kotlin
// 在 ViewModel 或 Repository 中使用
class UserViewModel : ViewModel() {

    fun loadUser(userId: Int) {
        viewModelScope.launch {
            try {
                // 就像调用本地方法一样简单！
                val user = RetrofitClient.apiService.getUser(userId)
                // 处理数据...
            } catch (e: Exception) {
                // 处理错误...
            }
        }
    }
}
```

## 注解详解

### HTTP 方法注解

| 注解 | HTTP 方法 | 用途 |
|-----|----------|------|
| `@GET` | GET | 获取数据 |
| `@POST` | POST | 提交数据 |
| `@PUT` | PUT | 更新数据（全量） |
| `@PATCH` | PATCH | 更新数据（部分） |
| `@DELETE` | DELETE | 删除数据 |
| `@HEAD` | HEAD | 只获取响应头 |
| `@OPTIONS` | OPTIONS | 查询支持的方法 |
| `@HTTP` | 自定义 | 自定义 HTTP 方法 |

### 参数注解

#### @Path - 路径参数

```kotlin
// URL: https://api.example.com/users/123
@GET("users/{id}")
suspend fun getUser(@Path("id") userId: Int): User

// 也可以指定不同的名字
@GET("users/{user_id}/posts/{post_id}")
suspend fun getPost(
    @Path("user_id") userId: Int,
    @Path("post_id") postId: Int
): Post
```

#### @Query - 查询参数

```kotlin
// URL: https://api.example.com/posts?userId=1&page=2
@GET("posts")
suspend fun getPosts(
    @Query("userId") userId: Int,
    @Query("page") page: Int
): List<Post>

// 可选参数（传 null 会自动忽略）
@GET("posts")
suspend fun searchPosts(
    @Query("keyword") keyword: String?,
    @Query("page") page: Int = 1  // 默认值
): List<Post>
```

#### @QueryMap - 多个查询参数

```kotlin
// 当参数很多或者动态时
@GET("search")
suspend fun search(@QueryMap options: Map<String, String>): SearchResult

// 使用
val options = mapOf(
    "q" to "android",
    "page" to "1",
    "sort" to "date"
)
apiService.search(options)
```

#### @Body - 请求体

```kotlin
// 把对象自动序列化成 JSON 放到请求体
@POST("users")
suspend fun createUser(@Body user: User): User

// Retrofit + Gson 自动把 User 对象转成 JSON：
// {"name":"张三","email":"zhangsan@example.com"}
```

#### @Field / @FormUrlEncoded - 表单参数

```kotlin
// 表单提交（application/x-www-form-urlencoded）
@FormUrlEncoded
@POST("login")
suspend fun login(
    @Field("username") username: String,
    @Field("password") password: String
): LoginResponse

// 多个表单字段
@FormUrlEncoded
@POST("feedback")
suspend fun submitFeedback(@FieldMap fields: Map<String, String>): Response
```

#### @Header / @Headers - 请求头

```kotlin
// 单个请求头
@GET("user")
suspend fun getUser(@Header("Authorization") token: String): User

// 多个静态请求头
@Headers(
    "Accept: application/json",
    "X-Custom-Header: custom-value"
)
@GET("user")
suspend fun getUserWithHeaders(): User

// 动态请求头
@GET("user")
suspend fun getUser(@HeaderMap headers: Map<String, String>): User
```

### 注解速查表

```
┌─────────────────────────────────────────────────────────────┐
│                       URL 组成部分                           │
├─────────────────────────────────────────────────────────────┤
│  https://api.example.com/users/123?page=1&size=10           │
│  └──────baseUrl───────┘ └─@GET─┘ └─@Query─┘                 │
│                         └@Path┘                             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                       请求体位置                             │
├─────────────────────────────────────────────────────────────┤
│  @Body      → 整个请求体（JSON）                             │
│  @Field     → 表单字段（需要 @FormUrlEncoded）               │
│  @Part      → 文件/文本部分（需要 @Multipart）               │
└─────────────────────────────────────────────────────────────┘
```

## 协程支持

Retrofit 2.6.0+ 原生支持 Kotlin 协程，只需要在接口方法加 `suspend` 关键字。

### 基本用法

```kotlin
interface ApiService {
    // 直接返回对象（suspend 函数）
    @GET("user/{id}")
    suspend fun getUser(@Path("id") id: Int): User

    // 返回 Response 包装，可以获取响应码、响应头
    @GET("user/{id}")
    suspend fun getUserResponse(@Path("id") id: Int): Response<User>
}
```

### 在 ViewModel 中使用

```kotlin
class UserViewModel : ViewModel() {
    private val _user = MutableStateFlow<User?>(null)
    val user: StateFlow<User?> = _user

    private val _error = MutableStateFlow<String?>(null)
    val error: StateFlow<String?> = _error

    fun loadUser(userId: Int) {
        viewModelScope.launch {
            try {
                _user.value = RetrofitClient.apiService.getUser(userId)
            } catch (e: HttpException) {
                // HTTP 错误（4xx, 5xx）
                _error.value = "服务器错误: ${e.code()}"
            } catch (e: IOException) {
                // 网络错误
                _error.value = "网络连接失败"
            }
        }
    }
}
```

### 协程 vs Callback

```kotlin
// ❌ 老方式：Callback（回调地狱）
apiService.getUser(1).enqueue(object : Callback<User> {
    override fun onResponse(call: Call<User>, response: Response<User>) {
        val user = response.body()
        // 又要请求 posts...
        apiService.getPosts(user!!.id).enqueue(object : Callback<List<Post>> {
            override fun onResponse(...) {
                // 嵌套嵌套嵌套...
            }
            override fun onFailure(...) { }
        })
    }
    override fun onFailure(call: Call<User>, t: Throwable) { }
})

// ✅ 新方式：协程（清爽！）
viewModelScope.launch {
    val user = apiService.getUser(1)
    val posts = apiService.getPosts(user.id)
    // 代码是同步写法，但实际异步执行
}
```

## Converter（数据转换器）

Converter 负责把 HTTP 响应体转换成你需要的对象，以及把对象转换成请求体。

### 常用 Converter

| Converter | 依赖 | 用途 |
|-----------|------|------|
| Gson | `converter-gson` | JSON ↔ 对象（最常用） |
| Moshi | `converter-moshi` | JSON ↔ 对象（Kotlin 友好） |
| kotlinx.serialization | 第三方库 | Kotlin 官方序列化 |
| Scalars | `converter-scalars` | String、基本类型 |
| Jackson | `converter-jackson` | JSON ↔ 对象 |

### Gson Converter（最常用）

```kotlin
// 添加依赖
implementation("com.squareup.retrofit2:converter-gson:2.9.0")

// 使用
Retrofit.Builder()
    .baseUrl(BASE_URL)
    .addConverterFactory(GsonConverterFactory.create())
    .build()
```

### Moshi Converter（推荐用于 Kotlin）

```kotlin
// 添加依赖
implementation("com.squareup.retrofit2:converter-moshi:2.9.0")
implementation("com.squareup.moshi:moshi-kotlin:1.15.0")

// 使用
val moshi = Moshi.Builder()
    .add(KotlinJsonAdapterFactory())
    .build()

Retrofit.Builder()
    .baseUrl(BASE_URL)
    .addConverterFactory(MoshiConverterFactory.create(moshi))
    .build()
```

### kotlinx.serialization Converter

```kotlin
// 添加依赖
implementation("org.jetbrains.kotlinx:kotlinx-serialization-json:1.6.0")
implementation("com.jakewharton.retrofit:retrofit2-kotlinx-serialization-converter:1.0.0")

// 数据类需要添加 @Serializable 注解
@Serializable
data class User(
    val id: Int,
    val name: String
)

// 使用
Retrofit.Builder()
    .baseUrl(BASE_URL)
    .addConverterFactory(Json.asConverterFactory("application/json".toMediaType()))
    .build()
```

## 横向对比

### Retrofit vs OkHttp vs Volley

| 对比项 | Retrofit | OkHttp | Volley |
|-------|----------|--------|--------|
| **定位** | RESTful API 封装 | HTTP 客户端 | 网络请求框架 |
| **使用方式** | 接口 + 注解 | 手动构建 Request | Request 类 |
| **数据解析** | 自动（Converter） | 手动 | 内置 JSON |
| **协程支持** | 原生支持 | 需要包装 | 不支持 |
| **学习成本** | 低 | 中 | 低 |
| **灵活性** | 中（有约束） | 高 | 低 |
| **适用场景** | RESTful API | 底层控制 | 简单请求 |
| **依赖** | 依赖 OkHttp | 无 | 无 |

### 什么时候用什么？

```
┌─────────────────────────────────────────────────────┐
│  你的需求是什么？                                    │
├─────────────────────────────────────────────────────┤
│                                                     │
│  调用标准 RESTful API？                              │
│     → Retrofit（最省心）                             │
│                                                     │

```

## 常见问题与解决方案

### 1. JSON 解析失败

**现象**：抛出 `JsonSyntaxException`

**原因**：字段名不匹配或类型不对

**解决**：
```kotlin
// 使用 @SerializedName 映射字段名
data class User(
    @SerializedName("user_id")  // 服务器返回的是 user_id
    val id: Int,
    @SerializedName("user_name")
    val name: String
)
```

### 2. 响应是数组，但只取一个元素

```kotlin
// 服务器返回 [{"id":1},{"id":2}]，但你只想要第一个
@GET("users")
suspend fun getUsers(): List<User>

// 在调用处取第一个
val firstUser = apiService.getUsers().firstOrNull()
```

### 3. 需要原始 Response

```kotlin
// 返回 Response<T> 可以获取响应码、响应头
@GET("user/{id}")
suspend fun getUser(@Path("id") id: Int): Response<User>

// 使用
val response = apiService.getUser(1)
if (response.isSuccessful) {
    val user = response.body()
} else {
    val errorCode = response.code()
    val errorBody = response.errorBody()?.string()
}
```

### 4. 超时配置

```kotlin
// 通过配置 OkHttpClient 来设置超时
val okHttpClient = OkHttpClient.Builder()
    .connectTimeout(30, TimeUnit.SECONDS)
    .readTimeout(30, TimeUnit.SECONDS)
    .writeTimeout(30, TimeUnit.SECONDS)
    .build()

val retrofit = Retrofit.Builder()
    .baseUrl(BASE_URL)
    .client(okHttpClient)  // 使用自定义的 OkHttpClient
    .addConverterFactory(GsonConverterFactory.create())
    .build()
```

## 最佳实践

### 1. 单例模式

```kotlin
// ✅ 推荐：整个 App 共享一个 Retrofit 实例
object RetrofitClient {
    val apiService: ApiService by lazy {
        createRetrofit().create(ApiService::class.java)
    }

    private fun createRetrofit(): Retrofit {
        return Retrofit.Builder()
            .baseUrl(BASE_URL)
            .client(createOkHttpClient())
            .addConverterFactory(GsonConverterFactory.create())
            .build()
    }

    private fun createOkHttpClient(): OkHttpClient {
        return OkHttpClient.Builder()
            .connectTimeout(15, TimeUnit.SECONDS)
            .readTimeout(15, TimeUnit.SECONDS)
            .build()
    }
}
```

### 2. 接口分模块

```kotlin
// 按功能拆分接口，不要一个接口几百个方法
interface UserApi {
    @GET("user/{id}")
    suspend fun getUser(@Path("id") id: Int): User
}

interface PostApi {
    @GET("posts")
    suspend fun getPosts(): List<Post>
}

interface AuthApi {
    @POST("login")
    suspend fun login(@Body request: LoginRequest): LoginResponse
}
```

### 3. 封装网络结果

```kotlin
// 统一的网络结果包装
sealed class NetworkResult<out T> {
    data class Success<T>(val data: T) : NetworkResult<T>()
    data class Error(val message: String, val code: Int? = null) : NetworkResult<Nothing>()
    object Loading : NetworkResult<Nothing>()
}

// Repository 层处理
class UserRepository {
    suspend fun getUser(id: Int): NetworkResult<User> {
        return try {
            val user = RetrofitClient.apiService.getUser(id)
            NetworkResult.Success(user)
        } catch (e: HttpException) {
            NetworkResult.Error("服务器错误", e.code())
        } catch (e: IOException) {
            NetworkResult.Error("网络连接失败")
        }
    }
}
```

## 面试检验

### Q1：Retrofit 和 OkHttp 是什么关系？

**答案**：Retrofit 是基于 OkHttp 的上层封装。OkHttp 负责底层的 HTTP 请求发送和接收，Retrofit 负责把接口定义翻译成 OkHttp 的 Request，并把 Response 转换成需要的对象。可以把 OkHttp 比作发动机，Retrofit 比作方向盘。

### Q2：Retrofit 是怎么把接口变成可调用的对象的？

**答案**：使用了 **Java 动态代理**。当调用 `retrofit.create(ApiService::class.java)` 时，Retrofit 会创建一个代理对象，当你调用接口方法时，实际上调用的是代理对象的 `invoke` 方法，在这个方法里 Retrofit 会解析注解、构建请求、发送请求、转换响应。

### Q3：为什么推荐使用 suspend 函数而不是 Call？

**答案**：
1. **代码更简洁**：避免回调嵌套
2. **异常处理更自然**：用 try-catch 而不是 onFailure 回调
3. **与协程生态兼容**：可以方便地使用 Flow、StateFlow
4. **取消更方便**：协程取消时请求自动取消

### Q4：Converter 的作用是什么？可以同时添加多个吗？

**答案**：Converter 负责数据转换，把响应体转成对象（ResponseBodyConverter），把对象转成请求体（RequestBodyConverter）。可以添加多个 Converter，Retrofit 会按顺序尝试，直到找到能处理的 Converter。常见用法是同时添加 GsonConverterFactory 和 ScalarsConverterFactory 来处理 JSON 和纯文本。

### Q5：@Query 和 @QueryMap 的区别？什么时候用哪个？

**答案**：
- `@Query`：单个查询参数，参数名固定
- `@QueryMap`：多个查询参数，参数名动态

使用场景：参数固定且少时用 @Query；参数很多或动态时用 @QueryMap。
