# Kotlin 协程学习指南

## 概述

Kotlin 协程（Coroutine）是 Android 官方推荐的**异步编程解决方案**，它让异步代码像同步代码一样简单易读。协程不是线程，而是一种更轻量级的并发方式——可以把它理解为"可以暂停和恢复的函数"。

> **一句话理解**：协程就像一个聪明的员工，遇到等待的事情（如网络请求）不会傻等，而是先去做其他事，等结果回来再继续之前的工作。线程就像傻员工，只会傻等。

## 为什么要学协程？

| 场景 | 没有协程（线程/回调） | 有协程 |
|-----|-------------------|-------|
| 网络请求 | 回调地狱 callback hell | 同步写法，一目了然 |
| 多个并行请求 | 手动管理线程同步，容易出错 | `async/await`，优雅并发 |
| 取消任务 | 需要手动管理，容易遗漏 | 结构化并发，自动取消 |
| 异常处理 | 多层回调中难以捕获 | try-catch 直接搞定 |
| 内存泄漏 | 线程持有 Activity 引用 | 配合 lifecycleScope 自动处理 |
| 代码可读性 | 回调嵌套，逻辑割裂 | 顺序执行，逻辑清晰 |

### 回调地狱 vs 协程

```kotlin
// 😱 回调地狱：依次请求用户信息、订单、商品详情
getUserInfo { user ->
    getOrders(user.id) { orders ->
        orders.firstOrNull()?.let { order ->
            getProductDetail(order.productId) { product ->
                // 终于拿到数据了...
                updateUI(user, order, product)
            }
        }
    }
}

// ✅ 协程：像写同步代码一样
suspend fun loadData() {
    val user = getUserInfo()           // 挂起，等待结果
    val orders = getOrders(user.id)    // 挂起，等待结果
    val product = getProductDetail(orders.first().productId)
    updateUI(user, orders.first(), product)
}
```

## 相关技术

| 技术 | 关系 | 说明 |
|-----|------|------|
| Lifecycle | 配合使用 | lifecycleScope 跟随生命周期自动取消 |
| ViewModel | 配合使用 | viewModelScope 跟随 ViewModel 生命周期 |
| Room | 原生支持 | DAO 方法可直接声明为 suspend 或返回 Flow |
| Retrofit | 原生支持 | 接口方法可直接声明为 suspend |
| Flow | 协程的一部分 | 协程的响应式流，替代 RxJava |
| StateFlow/SharedFlow | 协程的一部分 | 热流，替代 LiveData |

}
