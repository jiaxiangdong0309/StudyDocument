## 前置要求

- Android 开发基础（Activity/Service/权限）
- Kotlin 协程基础
- 建议准备一台真机 + 一个 BLE 外设（如手环、蓝牙灯）用于调试

## 版本基准

- Android 14 (API 34)
- JDK 17
- Kotlin 1.9+
