## 动态 URL

### @Url 注解

有时候 URL 不是固定的，比如：
- 图片 URL 由后端动态返回
- 需要根据环境切换 API 地址

```kotlin
interface ApiService {
    // @Url 会忽略 baseUrl，使用完整的传入 URL
    @GET
    suspend fun downloadFile(@Url fileUrl: String): ResponseBody
    
    // 也可以和其他参数混用
    @GET
    suspend fun getContent(
        @Url url: String,
        @Header("Authorization") token: String
    ): ResponseBody
}

// 使用
val imageData = apiService.downloadFile("https://cdn.example.com/image.jpg")
```

### 动态切换 BaseUrl

```kotlin
// 方法1：使用拦截器
class DynamicBaseUrlInterceptor : Interceptor {
    // 可以从外部动态设置
    var baseUrl: HttpUrl = "https://api.example.com/".toHttpUrl()
    
    override fun intercept(chain: Interceptor.Chain): Response {
        val originalRequest = chain.request()
        // 替换 host
        val newUrl = originalRequest.url.newBuilder()
            .scheme(baseUrl.scheme)
            .host(baseUrl.host)
            .port(baseUrl.port)
            .build()
        val newRequest = originalRequest.newBuilder()
            .url(newUrl)
            .build()
        return chain.proceed(newRequest)
    }
}

// 方法2：为不同环境创建不同的 Retrofit 实例
object ApiClient {
    private val BASE_URL = if (BuildConfig.DEBUG) {
        "https://dev.api.example.com/"
    } else {
        "https://api.example.com/"
    }
    
    val retrofit: Retrofit = Retrofit.Builder()
        .baseUrl(BASE_URL)
        .build()
}
```

### 上传进度监听

Retrofit 本身不支持进度监听，需要自定义 RequestBody：

```kotlin
// 带进度回调的 RequestBody
class ProgressRequestBody(
    private val delegate: RequestBody,
    private val onProgress: (bytesWritten: Long, totalBytes: Long) -> Unit
) : RequestBody() {
    
    override fun contentType() = delegate.contentType()
    
    override fun contentLength() = delegate.contentLength()
    
    override fun writeTo(sink: BufferedSink) {
        val totalBytes = contentLength()
        // 包装原始 sink，统计写入的字节数
        val countingSink = object : ForwardingSink(sink) {
            var bytesWritten = 0L
            
            override fun write(source: Buffer, byteCount: Long) {
                super.write(source, byteCount)
                bytesWritten += byteCount
                onProgress(bytesWritten, totalBytes)
            }
        }
        val bufferedSink = countingSink.buffer()
        delegate.writeTo(bufferedSink)
        bufferedSink.flush()
    }
}

// 使用
suspend fun uploadWithProgress(file: File, onProgress: (Float) -> Unit) {
    val requestBody = file.asRequestBody("image/*".toMediaType())
    val progressBody = ProgressRequestBody(requestBody) { written, total ->
        val progress = written.toFloat() / total
        onProgress(progress)
    }
    val part = MultipartBody.Part.createFormData("file", file.name, progressBody)
    apiService.uploadFile(part)
}
```

### 下载进度监听

```kotlin
// 方法1：通过拦截器
class DownloadProgressInterceptor(
    private val onProgress: (bytesRead: Long, totalBytes: Long) -> Unit
) : Interceptor {
    
    override fun intercept(chain: Interceptor.Chain): Response {
        val originalResponse = chain.proceed(chain.request())
        return originalResponse.newBuilder()
            .body(ProgressResponseBody(originalResponse.body!!, onProgress))
            .build()
    }
}

class ProgressResponseBody(
    private val delegate: ResponseBody,
    private val onProgress: (Long, Long) -> Unit
) : ResponseBody() {
    
    private var bufferedSource: BufferedSource? = null
    
    override fun contentType() = delegate.contentType()
    override fun contentLength() = delegate.contentLength()
    
    override fun source(): BufferedSource {
        if (bufferedSource == null) {
            bufferedSource = source(delegate.source()).buffer()
        }
        return bufferedSource!!
    }
    
    private fun source(source: Source): Source {
        return object : ForwardingSource(source) {
            var totalBytesRead = 0L
            
            override fun read(sink: Buffer, byteCount: Long): Long {
                val bytesRead = super.read(sink, byteCount)
                totalBytesRead += if (bytesRead != -1L) bytesRead else 0
                onProgress(totalBytesRead, contentLength())
                return bytesRead
            }
        }
    }
}
```

## 自定义 Converter

当后端返回的数据格式不是标准 JSON 时，需要自定义 Converter。

### 场景：后端返回包装格式

```json
{
    "code": 0,
    "message": "success",
    "data": { "id": 1, "name": "张三" }
}
```

```kotlin
// 统一响应包装
data class ApiResponse<T>(
    val code: Int,
    val message: String,
    val data: T?
)

// 自定义 Converter，自动解包
class UnwrapConverterFactory : Converter.Factory() {
    
    override fun responseBodyConverter(
        type: Type,
        annotations: Array<Annotation>,
        retrofit: Retrofit
    ): Converter<ResponseBody, *>? {
        // 包装成 ApiResponse<T> 类型
        val wrappedType = ParameterizedTypeImpl(ApiResponse::class.java, arrayOf(type))
        // 获取 Gson 的 Converter
        val delegate = retrofit.nextResponseBodyConverter<ApiResponse<Any>>(
            this, wrappedType, annotations
        )
        
        return Converter<ResponseBody, Any> { body ->
            val response = delegate.convert(body)
            // 检查业务状态码
            if (response?.code != 0) {
                throw ApiException(response?.code ?: -1, response?.message ?: "未知错误")
            }
            response.data
        }
    }
}

// 业务异常
class ApiException(val code: Int, override val message: String) : Exception(message)

// 使用
val retrofit = Retrofit.Builder()
    .baseUrl(BASE_URL)
    .addConverterFactory(UnwrapConverterFactory())  // 先添加自定义的
    .addConverterFactory(GsonConverterFactory.create())  // 再添加 Gson
    .build()

// 接口可以直接返回 data 部分的类型
interface ApiService {
    @GET("user/{id}")
    suspend fun getUser(@Path("id") id: Int): User  // 直接返回 User，不是 ApiResponse<User>
}
```

## CallAdapter

CallAdapter 决定了接口方法的返回类型。默认返回 `Call<T>`，通过 CallAdapter 可以支持其他类型。

### 常用 CallAdapter

| 返回类型 | 依赖 | 用途 |
|---------|------|------|
| `suspend fun(): T` | 内置 | 协程（推荐） |
| `Call<T>` | 内置 | 回调方式 |
| `Observable<T>` | adapter-rxjava3 | RxJava |
| `Flow<T>` | 第三方 | Kotlin Flow |
| `LiveData<T>` | 自定义 | 直接返回 LiveData |

### RxJava 支持

```kotlin
// 添加依赖
implementation("com.squareup.retrofit2:adapter-rxjava3:2.9.0")

// 配置
val retrofit = Retrofit.Builder()
    .baseUrl(BASE_URL)
    .addCallAdapterFactory(RxJava3CallAdapterFactory.create())
    .addConverterFactory(GsonConverterFactory.create())
    .build()

// 接口定义
interface ApiService {
    @GET("user/{id}")
    fun getUser(@Path("id") id: Int): Single<User>
    
    @GET("posts")
    fun getPosts(): Observable<List<Post>>
}
```

### 自定义 Flow CallAdapter

```kotlin
// Flow CallAdapter Factory
class FlowCallAdapterFactory : CallAdapter.Factory() {
    
    override fun get(
        returnType: Type,
        annotations: Array<Annotation>,
        retrofit: Retrofit
    ): CallAdapter<*, *>? {
        if (getRawType(returnType) != Flow::class.java) {
            return null
        }
        val responseType = getParameterUpperBound(0, returnType as ParameterizedType)
        return FlowCallAdapter<Any>(responseType)
    }
}

class FlowCallAdapter<R>(private val responseType: Type) : CallAdapter<R, Flow<R>> {
    
    override fun responseType() = responseType
    
    override fun adapt(call: Call<R>): Flow<R> = flow {
        val response = call.awaitResponse()
        if (response.isSuccessful) {
            emit(response.body()!!)
        } else {
            throw HttpException(response)
        }
    }
}

// 接口定义
interface ApiService {
    @GET("posts")
    fun getPosts(): Flow<List<Post>>
}

// 使用
apiService.getPosts()
    .catch { e -> /* 处理错误 */ }
    .collect { posts -> /* 处理数据 */ }
```

## 错误处理

### 统一错误处理

```kotlin
// 密封类定义所有可能的错误
sealed class NetworkError : Exception() {
    data class HttpError(val code: Int, val errorBody: String?) : NetworkError()
    data class NetworkException(val throwable: Throwable) : NetworkError()
    data class ApiError(val code: Int, val message: String) : NetworkError()
    object Unknown : NetworkError()
}

// 安全调用扩展函数
suspend fun <T> safeApiCall(apiCall: suspend () -> T): Result<T> {
    return try {
        Result.success(apiCall())
    } catch (e: HttpException) {
        val errorBody = e.response()?.errorBody()?.string()
        Result.failure(NetworkError.HttpError(e.code(), errorBody))
    } catch (e: IOException) {
        Result.failure(NetworkError.NetworkException(e))
    } catch (e: ApiException) {
        Result.failure(NetworkError.ApiError(e.code, e.message))
    } catch (e: Exception) {
        Result.failure(NetworkError.Unknown)
    }
}

// 在 Repository 中使用
class UserRepository {
    suspend fun getUser(id: Int): Result<User> = safeApiCall {
        apiService.getUser(id)
    }
}

// 在 ViewModel 中处理
viewModelScope.launch {
    userRepository.getUser(1)
        .onSuccess { user -> _user.value = user }
        .onFailure { error ->
            when (error) {
                is NetworkError.HttpError -> when (error.code) {
                    401 -> navigateToLogin()
                    404 -> showNotFound()
                    else -> showServerError()
                }
                is NetworkError.NetworkException -> showNetworkError()
                is NetworkError.ApiError -> showApiError(error.message)
                else -> showUnknownError()
            }
        }
}
```

### 全局错误处理拦截器

class ErrorHandlingInterceptor : Interceptor {
    
    override fun intercept(chain: Interceptor.Chain): Response {
        val response = chain.proceed(chain.request())
        
        // 根据响应码做全局处理
        when (response.code) {

            500, 502, 503 -> {

            }
        }
        
        return response
    }
}

## Token 刷新

### 使用 Authenticator

当收到 401 响应时，Authenticator 会被调用，可以在这里刷新 Token：

```kotlin
class TokenAuthenticator(
    private val tokenManager: TokenManager
) : Authenticator {
    
    override fun authenticate(route: Route?, response: Response): Request? {
        // 如果已经重试过，不再重试（避免死循环）
        if (responseCount(response) >= 3) {
            return null
        }
        
        // 同步刷新 Token
        val newToken = runBlocking {
            tokenManager.refreshToken()
        }
        
        return if (newToken != null) {
            // 用新 Token 重试请求
            response.request.newBuilder()
                .header("Authorization", "Bearer $newToken")
                .build()
        } else {
            null  // 刷新失败，不重试
        }
    }
    
    private fun responseCount(response: Response): Int {
        var count = 1
        var current = response.priorResponse
        while (current != null) {
            count++
            current = current.priorResponse
        }
        return count
    }
}

// Token 管理器
class TokenManager {
    private var accessToken: String? = null
    private var refreshToken: String? = null
    private val mutex = Mutex()  // 保证只刷新一次
    
    suspend fun refreshToken(): String? = mutex.withLock {
        return try {
            // 调用刷新接口（用单独的 Retrofit 实例，避免循环）
            val response = authApi.refreshToken(refreshToken!!)
            accessToken = response.accessToken
            refreshToken = response.refreshToken
            accessToken
        } catch (e: Exception) {
            null
        }
    }
}

// 配置 OkHttpClient
val client = OkHttpClient.Builder()
    .authenticator(TokenAuthenticator(tokenManager))
    .addInterceptor { chain ->
        // 添加 Token 到请求头
        val token = tokenManager.accessToken
        val request = if (token != null) {
            chain.request().newBuilder()
                .header("Authorization", "Bearer $token")
                .build()
        } else {
            chain.request()
        }
        chain.proceed(request)
    }
    .build()
```

## 缓存策略

### OkHttp 缓存

```kotlin
// 配置缓存
val cacheDir = File(context.cacheDir, "http_cache")
val cache = Cache(cacheDir, 10 * 1024 * 1024)  // 10MB

val client = OkHttpClient.Builder()
    .cache(cache)
    .addInterceptor(CacheInterceptor())

// 强制使用缓存的拦截器（无网络时）
class CacheInterceptor : Interceptor {
    override fun intercept(chain: Interceptor.Chain): Response {
        var request = chain.request()
        
        if (!isNetworkAvailable()) {
            // 无网络时强制使用缓存
            request = request.newBuilder()
                .cacheControl(CacheControl.FORCE_CACHE)
                .build()
        }
        
        return chain.proceed(request)
    }
}
```

## 边界认知：Retrofit 不适合的场景

### 1. 非 HTTP 协议

Retrofit 专门为 HTTP/HTTPS 设计，不支持：
- WebSocket（用 OkHttp 的 WebSocket）
- TCP/UDP（用 Socket）
- gRPC（用 grpc-kotlin）

### 2. 大文件流式处理

虽然 Retrofit 支持文件上传下载，但对于需要精细控制的场景：
- 断点续传 → 用 OkHttp + 自己实现
- 超大文件 → 考虑分片上传
- 实时流 → 用 OkHttp 的流式 API

### 3. 非 RESTful API

Retrofit 的注解是为 RESTful 设计的：
- GraphQL → 用专门的 GraphQL 客户端
- SOAP → 用其他库
- 自定义协议 → 直接用 OkHttp

### 4. 需要精细控制连接

如果需要：
- 自定义 DNS 解析
- 连接池精细调优
- 代理切换

这些要在 OkHttpClient 层面配置，Retrofit 只是上层封装。

## 面试检验

### Q1：Retrofit 如何实现文件上传进度监听？

**答案**：Retrofit 本身不支持进度监听，需要自定义 RequestBody。在自定义的 RequestBody 中重写 `writeTo()` 方法，包装原始的 Sink，在写入时统计已写入的字节数，通过回调通知进度。关键是使用 ForwardingSink 装饰器模式。

### Q2：Converter 和 CallAdapter 的区别是什么？

**答案**：
- **Converter**：负责数据格式转换，把 ResponseBody 转成对象，把对象转成 RequestBody。比如 GsonConverter 把 JSON 转成 Java 对象。
- **CallAdapter**：负责调用方式转换，把 Call 转成其他类型。比如 RxJavaCallAdapter 把 Call 转成 Observable。

简单说：Converter 管"数据长什么样"，CallAdapter 管"怎么拿数据"。

### Q3：如何优雅地处理 Token 过期自动刷新？

**答案**：使用 OkHttp 的 Authenticator。当服务器返回 401 时，Authenticator 会被调用，在这里同步调用刷新 Token 接口，成功后用新 Token 重建请求并重试。需要注意：1）加锁避免并发刷新；2）限制重试次数避免死循环；3）刷新接口用单独的 Retrofit 实例避免循环调用。

### Q4：为什么下载大文件要加 @Streaming 注解？

**答案**：不加 @Streaming 时，Retrofit 会把整个响应体加载到内存中再返回，大文件会导致 OOM。加了 @Streaming 后，返回的 ResponseBody 是流式的，可以边读边写到文件，内存占用很小。

### Q5：如何实现动态切换 BaseUrl？

**答案**：有两种方法：
1. **@Url 注解**：在方法参数上使用 @Url，传入完整 URL，会忽略 BaseUrl
2. **拦截器**：在拦截器中修改请求的 host，可以根据注解或 Header 动态决定使用哪个 BaseUrl

推荐第一种方法更简单，第二种适合需要全局切换的场景。

### Q6：多个 Converter 的添加顺序有什么讲究？

**答案**：Retrofit 会按添加顺序依次尝试 Converter，找到第一个能处理的就停止。所以：
1. 特殊 Converter 要放前面（如自定义的解包 Converter）
2. 通用 Converter（如 Gson）放后面
3. ScalarsConverterFactory 要放在 GsonConverterFactory 前面，否则 String 类型也会被 Gson 处理

### Q7：如何实现请求的取消？

**答案**：
- **协程方式**：取消协程作用域即可，Retrofit 会自动取消对应的请求
- **Call 方式**：保存 Call 对象，调用 `call.cancel()`

最佳实践是在 ViewModel 中使用 viewModelScope，ViewModel 销毁时自动取消所有请求。
